1. Czym jest program

HPL Tool Ultimate to jeden plik .exe dla Windows, który zbiera w jednym oknie rzeczy, po które zwykle sięga się do kilku osobnych programów: szybkie szukanie plików na całym dysku, narzędzia sieciowe, serwer do udostępniania plików w sieci domowej, drobne narzędzia codzienne i planowane wyłączanie komputera.

Program nie wymaga instalacji. Nie zapisuje się w Menu Start, nie zakłada wpisów odinstalowania i nie rozsypuje plików po systemie. Wszystko, czego potrzebuje — ikona, logo i baza producentów kart sieciowych — siedzi w środku pliku .exe.

Czego program nie robi

  • Nie szuka w chmurze ani na dyskach sieciowych innych komputerów — pracuje na dyskach widocznych w systemie.
  • Nie jest antywirusem ani programem do odzyskiwania danych.
  • Nie wysyła nigdzie Twoich plików. Jedyne połączenia z internetem to: sprawdzenie publicznego adresu IP (MOJE DANE), rozpoznanie kraju połączeń (opcja włączana ręcznie) i rozmowa z ruterem przy udostępnianiu przez UPnP.

4. Indeks plików

Szukanie po nazwie, rozmiarze, dacie i rozszerzeniu działa na indeksie — spisie plików zrobionym raz, z góry. Dzięki temu wyniki pojawiają się od razu, zamiast przeczesywać dysk przy każdym pytaniu.

Budowanie indeksu

  1. Wybierz zakres w polu „Dyski”. Cały system bierze wszystkie dyski stałe. Można też wskazać pojedynczy dysk albo — przyciskiem WYBIERZ FOLDER — jeden konkretny katalog.
  2. Kliknij BUDUJ INDEKS. Pasek stanu pokazuje, ile plików już policzono. Indeks całego dysku systemowego to zwykle kilka minut i kilkadziesiąt megabajtów pliku index.json.
  3. Później wystarczy ODŚWIEŻ INDEKS. Odświeżanie dopisuje zmiany zamiast budować spis od zera, więc trwa znacznie krócej. Gdy indeksu jeszcze nie ma, program mówi wprost: Nie ma czego odświeżać — zbuduj indeks od zera.

Data ostatniego indeksowania stoi na pasku stanu — dzisiaj, wczoraj albo konkretna data. Gdy indeksu nie ma, pasek pokazuje brak indeksu.

Wykluczenia

Przycisk WYKLUCZENIA otwiera listę katalogów pomijanych przy indeksowaniu. Domyślnie są to miejsca, w których i tak nie szuka się własnych plików: katalogi systemowe Windows, pliki tymczasowe, cache przeglądarek i foldery aktualizacji. Pomijanie ich skraca indeksowanie i zmniejsza plik indeksu.

  • Pomijaj wypisane katalogi (zalecane) — odznaczenie tego pola indeksuje wszystko, razem z katalogami systemowymi.
  • ZAPISZ zapamiętuje listę w index_cfg.json, DOMYŚLNE przywraca zestaw fabryczny.
Zmiana wykluczeń działa od następnego indeksowania. Istniejący indeks nie zmienia się sam — po zmianie listy zbuduj go ponownie.
Indeks to zdjęcie stanu dysku, nie podgląd na żywo. Plik skasowany po zaindeksowaniu nadal pojawi się w wynikach. Program rozpoznaje to przy otwieraniu i mówi, że pliku już nie ma — ale lista nie odświeża się sama. Po większych porządkach kliknij ODŚWIEŻ INDEKS.

6. Szukanie w treści i duplikaty

Szukanie w treści

Wpisz frazę w pole W treści, wskaż folder przyciskiem WYBIERZ FOLDER i kliknij SZUKAJ W TREŚCI. Program przechodzi pliki w tym folderze i podfolderach, i pokazuje każde trafienie razem z numerem linii i jej początkiem.

OgraniczenieWartość
Rodzaje plikówTylko pliki tekstowe: txt, log, ini, cfg, conf, csv, xml, json, md, py, bat, ps1, html, htm, css, js, sql, yaml, yml, srt, nfo, reg, env.
Największy plik20 MB. Większe pliki są pomijane, żeby jedno duże archiwum tekstowe nie zatrzymało całego szukania.
Liczba trafień1000. Po osiągnięciu limitu program przerywa i dopisuje przy podsumowaniu (limit trafień).
To nie jest wyszukiwarka dokumentów. Pliki .docx, .xlsx i .pdf są spakowane albo binarne — program ich nie otwiera i nie znajdzie w nich frazy. Szukanie w treści służy do plików tekstowych: konfiguracji, logów, napisów, kodu, plików CSV.
Fraza plus kryteria naraz. Gdy oprócz frazy wypełnisz nazwę, rozmiar, datę albo rozszerzenie i klikniesz SZUKAJ ŁĄCZONE, program najpierw zawęzi listę z indeksu, a dopiero w tych plikach poszuka treści. Przy bardzo dużej liczbie kandydatów zapyta, czy na pewno przeszukać ich treść — czytanie kilku tysięcy plików trwa.

Duplikaty

Przycisk DUPLIKATY PLIKÓW przegląda cały indeks i zestawia w grupy pliki, które mają tę samą nazwę i ten sam rozmiar. Okno pokazuje grupy posortowane od największych plików, po jednej grupie na sekcję, razem ze ścieżką każdej kopii.

  • ZAZNACZ KOPIE zaznacza w każdej grupie wszystko oprócz pierwszego pliku — czyli to, co można usunąć, zostawiając jeden egzemplarz.
  • USUŃ DO KOSZA przenosi zaznaczone pliki do Kosza, więc pomyłkę da się cofnąć.
  • Gdy grup jest więcej niż 200, okno pokazuje 200 największych i pisze o tym w nagłówku.
Zgodna nazwa i rozmiar to mocna, ale nie stuprocentowa przesłanka. Program nie liczy sum kontrolnych wszystkich plików na dysku — trwałoby to godzinami. Gdy chcesz mieć pewność, że dwa pliki są identyczne, policz ich sumy narzędziem SUMA KONTROLNA z rozdziału 13.

Hurtowa zmiana nazw

Przycisk ZMIEŃ NAZWY otwiera okno, w którym jedną regułą przemianujesz wszystkie pliki w wybranym folderze.

  • Zamień / na — podmienia fragment nazwy. IMG_ na Wakacje_ zamienia IMG_0041.jpg w Wakacje_0041.jpg.
  • Prefiks i Sufiks — dokładają tekst na początku albo na końcu nazwy, przed rozszerzeniem.
  • Numeruj (001, 002…) — dopisuje kolejny numer, w kolejności wyświetlania listy.

Pole PODGLĄD — STARA → NOWA pokazuje wynik reguły przed jej wykonaniem. Dopiero WYKONAJ zmienia nazwy naprawdę. Gdy reguła niczego nie zmienia, program mówi Brak zmian do wykonania i nie rusza plików.

Zawsze przeczytaj podgląd. To jedyny moment, w którym widać skutek reguły na wszystkich plikach naraz. Zmianę nazw też można cofnąć — patrz niżej.

Dziennik operacji i COFNIJ

Przycisk DZIENNIK w zakładce NARZĘDZIA otwiera zapis wszystkiego, co program zrobił z plikami: kopiowania, przeniesienia, usunięcia do Kosza i zmiany nazw. Każdy wpis ma datę, rodzaj i liczbę plików.

  • COFNIJ odwraca zaznaczoną operację — przywraca nazwy, kasuje kopie, wraca z przeniesieniem. Cofnięty wpis zostaje na liście z dopiskiem cofnięte.
  • Rodzaj zawęża listę do jednego typu operacji.
  • EKSPORT TXT zapisuje dziennik do pliku, ODŚWIEŻ przeładowuje go z dysku, WYCZYŚĆ kasuje całą historię po potwierdzeniu.
Nie wszystko da się cofnąć. Przy wpisach, których odwrócenie nie jest możliwe — bo plik docelowy już nie istnieje albo został w międzyczasie zmieniony — program mówi Tego wpisu nie da się cofnąć zamiast działać po omacku. Usunięcie do Kosza odwraca się przez Kosz Windows.

Osobny port dla pliku

Czasem druga strona nie potrafi dopisać numeru ani nazwy do adresu i oczekuje, że pod całym adresem będzie jeden konkretny plik. Do tego służy port przypisany do pozycji na liście: wpisz numer portu przy pliku, a program uruchomi dla niego osobny serwer, w którym każdy adres zwraca ten jeden plik.

  • Port musi być z zakresu 1024–65535.
  • Jeden port obsługuje jeden plik — program nie pozwoli przypisać tego samego portu dwa razy i powie Ten port jest już przypisany do innego pliku.
  • KOPIUJ PORT kopiuje gotowy adres w postaci http://192.168.1.50:8890/.

W ten sposób dwa różne pliki można wystawić pod dwoma różnymi adresami: http://192.168.1.50:8890/ i http://192.168.1.50:8891/ — każdy zwraca swój plik, niezależnie od tego, co dopisze klient.

Hasło, UPnP i odbiór plików

  • Wymagaj hasła — włącza logowanie. Wpisz LOGIN i HASŁO albo kliknij GENERUJ, a program wymyśli je za Ciebie. POKAŻ odsłania hasło, KOPIUJ ADRES Z HASŁEM daje gotowy odnośnik z danymi logowania w środku.
  • Pozwól wysyłać pliki na komputer — dokłada stronę /upload, przez którą telefon albo inny komputer wyśle plik do Ciebie. Przycisk FOLDER ODBIORU wskazuje, gdzie te pliki mają lądować.
  • Udostępnij w internecie (UPnP) — prosi ruter o przepuszczenie portu z zewnątrz. Program pokazuje wtedy Rozmawiam z ruterem…, a po udanej rozmowie podaje adres publiczny i pozwala pokazać go jako kod QR.
UPnP wystawia plik na cały internet. Używaj go tylko wtedy, gdy naprawdę musisz przesłać coś poza dom, i zawsze razem z hasłem. Po skończonej wysyłce zatrzymaj serwer przyciskiem ZATRZYMAJ SERWER — wtedy przekierowanie przestaje działać. Nie wszystkie rutery mają UPnP włączone; gdy ruter odmówi, program powie o tym wprost.
Serwer umie przewijanie. Obsługuje żądania zakresu, więc film otwarty z tego adresu w odtwarzaczu można przewijać, a przerwane pobieranie da się wznowić. Zmiany na liście plików działają na żywo — dodanie albo usunięcie pozycji nie wymaga restartu serwera.
Zapora Windows zapyta raz. Przy pierwszym uruchomieniu serwera system pyta o zgodę na połączenia przychodzące. Trzeba ją dać dla sieci prywatnych, inaczej inne urządzenia nie zobaczą adresu.

11. Narzędzia sieciowe

SKANER SIECI

Przegląda całą sieć domową i pokazuje, co jest w niej włączone: adres IP, nazwę urządzenia i producenta karty sieciowej rozpoznanego z adresu MAC. Nazwy ustala z DNS i NetBIOS, więc telewizor czy drukarka zwykle podpisują się same.

Rozpoznane urządzenia zapisują się w pliku ipinfo.json, dzięki czemu przy następnym skanowaniu lista jest od razu opisana. Przyciski +WOL i PORTY przy wierszu przenoszą urządzenie do Wake on LAN albo od razu skanują jego porty.

POŁĄCZENIA

Pokazuje, co i dokąd wysyła dane z tego komputera: adres lokalny, adres zdalny, stan połączenia i proces, który je nawiązał.

  • Szukaj procesu zawęża listę do jednej nazwy programu.
  • Tylko zewnętrzne ukrywa ruch wewnątrz komputera i sieci lokalnej, zostawiając to, co wychodzi na świat.
  • Tylko ESTABLISHED zostawia połączenia faktycznie nawiązane, bez nasłuchujących portów.
  • Sprawdzaj kraj online dopisuje kraj i organizację właściciela adresu. To jedyna opcja w tym oknie, która sama łączy się z internetem — domyślnie jest wyłączona.
  • ZABLOKUJ W ZAPORZE ADMIN zakłada regułę zapory blokującą wskazany program.
Bez uprawnień administratora część procesów pokaże się bez ścieżki do pliku — Windows nie udostępnia jej zwykłemu użytkownikowi. Sama lista połączeń działa normalnie.

SKANER PORTÓW

Sprawdza, które porty są otwarte na wskazanym adresie. Do wyboru typowe porty albo własny zakres w postaci 80,443,8000-8100. Przy otwartych portach program próbuje rozpoznać usługę i pokazuje jej pierwszą odpowiedź, więc widać nie tylko „port 22 otwarty”, ale i co za nim stoi. Zakres jest ograniczony do 8000 portów na jedno skanowanie, a PRZERWIJ zatrzymuje pracę w dowolnym momencie.

Skanuj tylko własne urządzenia. Skanowanie portów cudzych adresów bywa traktowane jak próba włamania i może naruszać regulamin dostawcy internetu.

TRASA (TRACEROUTE)

Pokazuje kolejne węzły, przez które przechodzą pakiety do wskazanego adresu, razem z czasami. Po tym widać, czy zacięcie jest u Ciebie, u dostawcy, czy dopiero gdzieś dalej w drodze.

DLACZEGO NIE MA INTERNETU?

Diagnostyka, która przechodzi połączenie odcinek po odcinku — karta sieciowa, adres IP, ruter, DNS, wyjście na świat — i pisze przy każdym etapie, czy jest w porządku. Zamiast zgadywać, dostajesz gotową odpowiedź, na którym kroku się zatrzymało. KOPIUJ RAPORT przenosi wynik do schowka — do wysłania do pomocy technicznej.

MONITOR TRANSFERU

Pokazuje bieżącą prędkość pobierania i wysyłania dla wybranej karty, sumę od otwarcia okna i wykres z ostatnich 60 sekund. Odpowiada na pytanie „czy coś w tle zjada łącze”.

WAKE ON LAN

Budzi komputery w sieci lokalnej pakietem magicznym. Urządzenie dodaje się raz — Nazwa, MAC i IP, przycisk DODAJ — a potem wystarczy OBUDŹ. Lista zapisuje się w wol.json, więc przeżywa zamknięcie programu.

Wake on LAN musi być włączone po drugiej stronie — w BIOS-ie budzonego komputera i we właściwościach jego karty sieciowej. Program tylko wysyła pakiet; jeśli komputer go ignoruje, ustawienia są po tamtej stronie.

WI-FI

Okno pokazuje trzy rzeczy naraz: stan własnego połączenia (SSID, sygnał, kanał i pasmo, prędkość, zabezpieczenie), obłożenie kanałów w postaci wykresu i listę sieci w otoczeniu.

Pod wykresem program podaje najlepszy wolny kanał w paśmie 2,4 GHz i 5 GHz — to gotowa podpowiedź, co ustawić w ruterze, gdy Wi-Fi zwalnia w godzinach szczytu. SKANUJ OTOCZENIE odświeża listę, KOPIUJ LISTĘ przenosi ją do schowka.

Gdy komputer nie ma karty Wi-Fi albo usługa WLAN jest wyłączona, okno mówi to wprost (Brak karty Wi-Fi, Usługa WLAN nie działa) zamiast pokazywać pustą listę.

ZMIEŃ MAC

ADMIN Zmienia adres MAC wybranej karty sieciowej. LOSUJ generuje losowy adres prywatny, ZMIEŃ MAC zapisuje go i restartuje kartę, a PRZYWRÓĆ FABRYCZNY wraca do adresu sprzętowego.

W trakcie zmiany karta na chwilę znika z systemu — połączenie zrywa się i wraca po kilku sekundach. Jeśli ruter przydziela adresy po MAC albo filtruje po nim dostęp, po zmianie komputer może nie dostać adresu, dopóki nie wrócisz do fabrycznego.

12. Zakładka NARZĘDZIA

Zbiór drobnych narzędzi, po które normalnie sięga się do osobnych programów. Każdy przycisk otwiera własne okno — można mieć kilka otwartych naraz.

ZRZUT EKRANU

Robi zrzut całego ekranu i zapisuje go do folderu programu. Dwa ustawienia obok przycisku zmieniają sposób działania:

  • Opóźnienie (s) — od 0 do 60 sekund. Czas na otwarcie menu albo okna, które ma znaleźć się na zrzucie.
  • ukryj okno programu — na czas zrzutu HPL Tool Ultimate chowa się, żeby nie zasłaniał tego, co chcesz uwiecznić.
  • OTWÓRZ OSTATNI — otwiera ostatnio zrobiony zrzut. Gdy żadnego jeszcze nie ma, otwiera folder programu.

SCHOWEK (HISTORIA)

Program zapamiętuje, co kopiowałeś, i pozwala wrócić do wcześniejszych wpisów — także po ponownym uruchomieniu, bo historia leży w pliku clipboard.json.

Historia schowka to zwykły plik tekstowy obok programu. Jeśli kopiujesz hasła albo dane, których nie chcesz zostawiać na dysku, czyść historię po pracy — albo nie trzymaj programu na komputerze współdzielonym z innymi.

SZYBKIE NOTATKI

Jedno pole tekstowe, które zapisuje się samo. W trakcie pisania program pokazuje pisanie…, a po zapisaniu — wczytano. Treść leży w notes.txt obok programu, więc można ją czytać i edytować zwykłym notatnikiem. WSTAW DATĘ dopisuje bieżącą datę i godzinę — wygodne przy prowadzeniu dziennika prac.

GENERATOR HASEŁ

Generuje kilka haseł naraz. Suwak DŁUGOŚĆ ustala liczbę znaków, a opcja pomiń znaki mylące wyrzuca z puli zera i litery O, jedynki oraz małe l i duże I, a także znaki łatwe do pomylenia przy przepisywaniu. Kliknięcie w wynik kopiuje go do schowka — pod listą pojawia się wtedy potwierdzenie SKOPIOWANE.

Wyłącz „pomiń znaki mylące” dla haseł, których nigdy nie przepisujesz ręcznie. Pełna pula znaków daje mocniejsze hasło. Ograniczenie ma sens tylko wtedy, gdy hasło trzeba będzie komuś podyktować albo przepisać z kartki.

KEEP AWAKE

Blokuje usypianie komputera i wygaszanie ekranu — na czas długiego kopiowania, renderowania albo pobierania. Włączony przycisk zmienia kolor na fioletowy i napis na KEEP AWAKE — AKTYWNY. Ponowne kliknięcie wyłącza blokadę i oddaje sterowanie ustawieniom Windows.

WYCZYŚĆ TEMP

PIN Kasuje pliki tymczasowe z %TEMP% i C:\Windows\Temp oraz opróżnia Kosz. Program pyta o potwierdzenie i wymienia te trzy miejsca, a po pracy podaje, ile plików usunął i ile miejsca odzyskał. Pliki zajęte przez działające programy są pomijane — to normalne i nie jest błędem.

Opróżnienie Kosza jest nieodwracalne. Jeśli korzystasz z funkcji Usuń do kosza w innych częściach programu jako zabezpieczenia przed pomyłką, sprawdź Kosz, zanim uruchomisz czyszczenie.

ZMIEŃ PIN

Pyta o stary PIN, potem o nowy. Nowy zapisuje się w postaci skrótu w pliku pin.dat. Skasowanie tego pliku przywraca PIN fabryczny 0000 — warto o tym pamiętać, gdy PIN wypadnie z głowy.

13. Narzędzia systemowe

RAPORT SYSTEMU

Zbiera w jedno okno komplet danych serwisowych: procesor, pamięć, płytę główną i BIOS, system i jego wersję, karty sieciowe, a także listę dysków z ich rozmiarem i wolnym miejscem. KOPIUJ RAPORT przenosi całość do schowka.

To pierwsza rzecz, o którą prosi serwis albo pomoc techniczna. Zamiast czytać dane z pięciu okien systemu, wyślij jeden gotowy raport.

MENEDŻER AUTOSTARTU

Pokazuje programy uruchamiane razem z Windows i pozwala je wyłączyć. Wyłączone wpisy trafiają do kopii autostart_backup.json, więc da się je przywrócić — narzędzie nie kasuje ich bezpowrotnie.

Nie wyłączaj wpisów, których nie rozpoznajesz. W autostarcie siedzą też sterowniki dźwięku, obsługa touchpada i oprogramowanie karty graficznej. Wyłączaj to, co znasz i czego nie potrzebujesz od razu po starcie.

SUMA KONTROLNA

Liczy sumę kontrolną pliku — MD5, SHA-1 albo SHA-256. Służy do sprawdzenia, czy pobrany plik jest kompletny i taki sam jak u wydawcy.

  1. PRZEGLĄDAJ — wskaż plik. Przy dużych plikach widać postęp; liczenie można przerwać.
  2. LICZ — w polu WYNIK pojawia się suma.
  3. PORÓWNAJ Z — wklej sumę podaną przez wydawcę. Program odpowie ✔ ZGODNE albo ✘ NIEZGODNE, bez wpatrywania się w ciąg znaków.

SNAPSHOT FOLDERU

Odpowiada na pytanie „co się w tym folderze zmieniło”. Działa w dwóch krokach: najpierw ZAPISZ SNAPSHOT zapamiętuje stan folderu, a później PORÓWNAJ ZE SNAPSHOTEM pokazuje trzy listy: NOWE, USUNIĘTE i ZMIENIONE.

Porównanie bierze pod uwagę rozmiar, datę i sumę kontrolną każdego pliku, więc wyłapuje też podmianę pliku o tej samej nazwie i wielkości. Czytanie dużego folderu trwa — pracę można przerwać, a program powie wtedy Anulowano.

Przydaje się przed instalacją nieznanego programu i po niej, przy sprawdzaniu, co zmieniła aktualizacja, i przy pilnowaniu katalogu z kopiami zapasowymi.

Zapora Windows

ADMIN PIN Trzy przyciski i jedno pole Aplikacja, w którym wskazujesz plik .exe przyciskiem PRZEGLĄDAJ:

  • ZABLOKUJ zakłada regułę zapory odcinającą wskazany program od sieci — w obie strony, wychodzącą i przychodzącą.

1. What the program is

HPL Tool Ultimate is a single .exe file for Windows that brings together, in one window, the things you would normally open several separate programs for: fast file search across the whole disk, network tools, a file server for the home network, small everyday utilities and scheduled shutdown.

The program needs no installation. It does not appear in the Start menu, creates no uninstall entries and scatters no files around the system. Everything it needs — the icon, the logo and the network-card vendor database — sits inside the .exe file.

Four tabs

TabWhat it is for
SEARCHThe file index and searching by name, size, date, extension or content. Duplicates, batch rename, the “what eats the disk” report. This is the default tab — it opens right after start.
NETWORKPing, DNS, network and port scanners, traceroute, traffic monitor, Wake on LAN, Wi-Fi, MAC change, the file server and the “why is there no internet” diagnostics.
TOOLSScreenshots, clipboard history, notes, password generator, checksums, folder snapshot, startup manager, system report, firewall, TEMP cleaning, Keep Awake.
POWERShutdown, restart, hibernation, sleep and log off — now, in X minutes, at a given time or daily at a fixed hour. Restart to BIOS.

What the program does not do

  • It does not search the cloud or network drives of other computers — it works on disks visible in the system.
  • It is not an antivirus and not a data recovery tool.
  • It does not send your files anywhere. The only internet connections it makes are: checking the public IP address (MY DATA), resolving the country of remote connections (an option you switch on yourself) and talking to the router when sharing through UPnP.
Working data is kept next to the .exe file. The index, notes, PIN, clipboard history and the remaining settings are written into the same folder the program sits in. Moving that folder to another disk or a USB stick takes them along — see chapter 3.

4. The file index

Searching by name, size, date and extension works on an index — a list of files made once, in advance. That is why results appear instantly instead of combing through the disk on every question.

Building the index

  1. Choose the scope in the “Drives” field. All drives takes every fixed disk. You can also pick a single drive or — with SELECT FOLDER — one particular directory.
  2. Click BUILD INDEX. The status bar shows how many files have been counted. Indexing a whole system disk usually takes a few minutes and produces an index.json of a few dozen megabytes.
  3. Afterwards REFRESH INDEX is enough. Refreshing adds the changes instead of rebuilding the list, so it is much quicker. With no index yet, the program says plainly: Nothing to refresh — build the index first.

The date of the last indexing sits on the status bar — today, yesterday or an actual date. With no index at all, the bar shows no index.

Exclusions

The EXCLUSIONS button opens the list of folders skipped while indexing. By default these are places where you would not look for your own files anyway: Windows system folders, temporary files, browser caches and update folders. Skipping them shortens indexing and shrinks the index file.

  • Skip the listed folders (recommended) — clearing this box indexes everything, system folders included.
  • SAVE stores the list in index_cfg.json, DEFAULTS restores the factory set.
Changed exclusions take effect from the next indexing. An existing index does not change by itself — rebuild it after editing the list.
The index is a snapshot of the disk, not a live view. A file deleted after indexing will still appear in the results. The program notices this when opening it and says the file is gone — but the list does not refresh itself. After a big clean-up, click REFRESH INDEX.

The FILE DUPLICATES button goes through the whole index and groups files that share the same name and the same size. The window shows the groups sorted from the largest files down, one group per section, with the path of every copy.
