1. Czym jest plugin

HPL ink IPTV to plugin (wtyczka) dla dekoderów satelitarnych z systemem Enigma2. Odtwarza kanały, filmy i seriale z list IPTV, pokazuje program telewizyjny i przypomina o audycjach. Listy, przewodnik i ustawienia wygodnie dodaje się z komputera albo telefonu, przez panel w przeglądarce.

  • Listy M3U / M3U8 z adresu URL, z pliku z komputera albo z konta Xtream Codes (serwer, login, hasło).
  • Kanały TV w trzech kolumnach: bukiety, kanały i karta bieżącej audycji.
  • Własny odtwarzacz z OSD, listą kanałów, paskiem kafelków, przypomnieniami i automatyczną naprawą zatrzymanego obrazu.
  • Filmy ze ścianą plakatów, seriale z kolejnym odcinkiem, wznawianie oglądania od miejsca przerwania.
  • Przewodnik XMLTV z automatycznym importem, wyszukiwanie w programie, przypomnienia z wyborem „Przypomnij” albo „Przełącz”.
  • Ulubione, historia, lista „Do obejrzenia”, polski i angielski język.
Sieć: dekoder, komputer i telefon muszą być w tej samej sieci domowej. Panel nie jest stroną w internecie — działa tylko w domu, pod adresem pokazanym na TV.

2. Sprzęt i oprogramowanie

Na czym plugin był testowany

DekoderOprogramowaniePython
VU+ Duo 4K SEOpenBH 5.xPython 3.12
VU+ Solo 4KOpenBH 5.xPython 3.12

Dodatkowo plugin sprawdzono na OpenBH 6.0 (Python 3.14) — działa prawidłowo po doinstalowaniu jednego pakietu, python3-sqlite3 (rozdział 3).

Odtwarzanie sprawdzono na obu odtwarzaczach Enigmy: GStreamer (4097) i exteplayer3 (5002) z wtyczką ServiceApp.

Inne dekodery i systemy: plugin jest napisany w czystym Pythonie i korzysta ze standardowych elementów Enigmy2. Teoretycznie powinien działać także na innych dekoderach i innych systemach opartych na Enigmie2 z tą samą wersją Pythona (Python 3.12 lub 3.14), np. na innych modelach VU+ czy innych obrazach z tej samej generacji. Takie zestawy nie były jednak sprawdzane.
Systemy ze starszym Pythonem 2.7 (np. OpenATV 6.x) nie są obsługiwane przez tę wersję pluginu.

Wymagania

  • Dekoder z Enigmą2 podłączony do sieci domowej (kabel albo Wi-Fi).
  • Lista IPTV od Twojego dostawcy: adres M3U, plik M3U albo dane konta Xtream Codes.
  • Dostęp do dekodera przez FTP / SFTP (np. WinSCP, FileZilla) i Telnet / SSH (np. PuTTY) — tylko do instalacji.
  • Moduł Pythona python3-sqlite3 — w OpenBH 5.x jest w obrazie, w OpenBH 6.0 trzeba go doinstalować (rozdział 3).

3. Instalacja

1. PlikSkopiuj enigma2-plugin-extensions-hpliptv_2.01_all.ipk do katalogu /tmp na dekoderze (FTP / SFTP).
2. InstalacjaZaloguj się do dekodera przez Telnet / SSH i wpisz polecenie instalacji (poniżej).
3. Restart GUIZrestartuj interfejs: Menu → Standby / Restart → Restart GUI.
4. StartPlugin jest w Menu → Wtyczki oraz w menu rozszerzeń (Extensions) jako HPL ink IPTV.

Polecenie instalacji:

opkg install /tmp/enigma2-plugin-extensions-hpliptv_2.01_all.ipk

Aktualizacja do nowszej wersji wygląda tak samo — nowy pakiet zastępuje stary, ustawienia i listy zostają. Odinstalowanie: opkg remove enigma2-plugin-extensions-hpliptv.

OpenBH 6.0 — wymagany dodatkowy pakiet. W obrazie OpenBH 6.0 nie ma modułu bazy danych Pythona, w którym plugin zapisuje przewodnik EPG. Bez niego import EPG kończy się komunikatem „Brak modułu sqlite3 w systemie - EPG nie ma gdzie zapisać”. Po instalacji pluginu, przed pierwszym importem EPG, wpisz w Telnet / SSH:

opkg update && opkg install python3-sqlite3

i zrestartuj GUI. W OpenBH 5.x ten pakiet jest już w obrazie — nic nie trzeba doinstalowywać. Sprawdzenie, czy pakiet jest: opkg list-installed | grep python3-sqlite3.

Odtwarzacz exteplayer3 (opcjonalnie)

Domyślnie plugin gra przez GStreamer (4097), który jest w każdym obrazie. Drugi odtwarzacz, exteplayer3 (5002), bywa lepszy przy kanałach o dużej przepływności. Wymaga wtyczki ServiceApp z repozytorium Twojego systemu:

opkg update && opkg install enigma2-plugin-systemplugins-serviceapp

Po restarcie GUI wybierz w Ustawieniach pluginu Odtwarzacz: exteplayer3 (5002). Gdy ServiceApp nie jest zainstalowany, plugin sam gra przez GStreamer i mówi o tym komunikatem.

ServiceApp musi pasować do systemu. Instaluj go wyłącznie z repozytorium tego samego obrazu, który masz na dekoderze. Pakiet z innego obrazu albo starszego archiwum może się nie wczytać i dać czarny ekran na exteplayer3.

4. Pierwsze uruchomienie

Przy pierwszym starcie plugin nie ma jeszcze żadnej listy. Najprościej dodać ją przez panel w przeglądarce.

  1. W pluginie wybierz Panel WWW (PC) TV. Na ekranie pojawi się adres panelu, np. http://192.168.1.50:8098, kod QR i klucz dostępu.
  2. Otwórz ten adres w przeglądarce komputera albo zeskanuj kod QR telefonem PANEL.
  3. W panelu przejdź do Ustawienia → Dodaj listę (albo przycisk Dodaj listę na stronie Start) i wpisz adres listy albo dane Xtream Codes. Plik z komputera dodasz w tym samym miejscu: Wgraj plik .m3u z komputera.
  4. Lista pobierze się na dekoder. Wróć do pluginu na TV — kanały, filmy i seriale są gotowe.
  5. Przewodnik EPG pobiera się sam (źródło „Auto PL”). Można go też zaimportować od razu: EPG i przypomnienia → Importuj EPG TV.
Bez komputera: adres listy można wpisać także na TV, w Ustawienia i narzędzia → Ustawienia → Źródło 1, klawiszem ŻÓŁTY (edycja), a potem wybrać Odśwież listę M3U.

7. Odtwarzacz

Po włączeniu kanału lub filmu pojawia się OSD: numer i grupa kanału, nazwa, zegar, logo, tytuł audycji, godzina początku i końca, fioletowy pasek postępu, następna audycja i podpowiedzi klawiszy. OSD chowa się samo po czasie ustawionym w Czas paska OSD.

Menu odtwarzacza — klawisz MENU

  • Opis audycji i Przewodnik kanału — bez przerywania oglądania, obraz gra pod spodem.
  • Przypomnij: GG:MM tytuł albo Przełącz: GG:MM tytuł — przypomnienie o następnej audycji tego kanału; przy już ustawionym — Usuń przypomnienie.
  • Przypomnienia — lista wszystkich zaplanowanych przypomnień, na półprzezroczystym tle.
  • Historia — ostatnio oglądane pozycje, z przełączeniem bez wychodzenia z odtwarzacza.

Zapowiedzi i przypomnienia na obrazie

  • Mały pasek postępu w prawym dolnym rogu, gdy OSD jest schowane (można wyłączyć).
  • Zapowiedź następnej audycji na wybraną liczbę minut przed jej początkiem.
  • Panel „Później” — trzy nadchodzące audycje pod koniec bieżącej.
  • Przypomnienie — belka w prawym dolnym rogu: „Za 10 min · kanał”, a w chwili startu „Zaczyna się · kanał” albo „Przełączam · kanał”. Gdy plugin nie gra, przypomnienie pojawia się w oknie Enigmy. Czekające przypomnienie sygnalizuje kropka w OSD.

Gdy obraz stanie

Plugin sam pilnuje strumienia. Gdy obraz stoi dłużej niż kilkanaście sekund, pojawia się komunikat „Przywracam obraz…” i plugin próbuje odbudować połączenie — do trzech razy. Jeśli to nie pomoże, a na liście jest drugi kanał o tej samej nazwie (zapasowe łącze), plugin przełącza się na niego. Przy braku sieci czeka na jej powrót.

Filmy i seriale w odtwarzaczu

Film przerwany w połowie zapamiętuje miejsce — przy ponownym włączeniu plugin proponuje kontynuację. Po skończonym odcinku serialu włącza się następny.

9. Moje i Szukaj

Moje

  • Kontynuuj oglądanie — filmy i odcinki przerwane w połowie.
  • Ulubione — kanały i pozycje oznaczone klawiszem ŻÓŁTY.
  • Do obejrzenia — filmy odłożone na później.
  • Ostatnio oglądane — historia.

Szukaj

  • Szukaj filmu/pozycji — w filmach i serialach z listy, z klawiatury ekranowej.
  • Szukaj w programie (EPG) — w tytułach audycji całego przewodnika, od teraz w przód. W wynikach: OK włącza kanał trwającej audycji, ZIELONY ustawia przypomnienie, ŻÓŁTY przełączenie kanału.

Kanały szuka się na liście kanałów, klawiszem NIEBIESKI.

10. EPG i przypomnienia

Przewodnik EPG

Plugin korzysta z przewodnika w formacie XMLTV. Źródło wybiera się w Ustawieniach:

  • Auto PL (domyślnie) — zestaw polskich przewodników z internetu.
  • url-tvg z listy M3U — adres przewodnika zapisany w samej liście.
  • Własny URL XMLTV — dowolny adres pliku .xml lub .xml.gz.

Przy liście z Xtream Codes przewodnik ustawia się sam z serwera Xtream, gdy lista nie poda własnego. Import uruchamia się automatycznie co 48 godzin i nie przeszkadza w oglądaniu — gdy coś gra, czeka. Ręcznie: EPG i przypomnienia → Importuj EPG TV.

Dopasowanie EPG

Gdy kanał nie ma programu, choć inne mają, przypisz mu właściwy kanał przewodnika: EPG i przypomnienia → Dopasowanie EPG. OK przypisuje, NIEBIESKI filtruje po nazwie, ŻÓŁTY kasuje przypisanie. To samo można zrobić w panelu, w Ustawienia → Przewodnik EPG → Dopasowanie EPG.

Przypomnienia

Przypomnienie ustawia się przy przyszłej audycji: w przewodniku kanału, w wynikach szukania w programie, w menu kanału, w menu odtwarzacza albo w panelu. Każde przypomnienie ma rodzaj:

RodzajCo się stanie, gdy audycja się zacznieGdzie ustawić
Przypomnijtylko komunikat na obrazieZIELONY TV, przycisk „Przypomnij” PANEL
Przełączplugin przełącza na kanał audycjiŻÓŁTY TV, przycisk „Przełącz” PANEL

Lista wszystkich przypomnień: EPG i przypomnienia → Przypomnienia albo MENU w odtwarzaczu. CZERWONY lub ŻÓŁTY kasuje zaznaczone. Przypomnienia, które przełączą kanał, mają znacznik PRZEŁĄCZY. Wcześniejsze uprzedzenie (5–30 minut) ustawia się w Ustawieniach.

11. Panel w przeglądarce

Panel to strona serwowana przez sam dekoder. Adres i klucz dostępu pokazuje pozycja Panel WWW (PC) na ekranie startowym — z kodem QR dla telefonu. Adres ma postać http://IP-dekodera:8098. Adres z kluczem nie powinien wychodzić poza dom.

Pasek telewizora

U góry panelu jest pasek tego, co gra na dekoderze, z przyciskami sterowania: poprzedni / następny kanał, przewijanie, pauza, stop, głośność i wyciszenie.

Przypomnienia z panelu

W oknie programu kanału (zakładka Kanały → program) przy każdej przyszłej audycji są dwa przyciski: Przypomnij i Przełącz. Przy trwającej audycji — Włącz. Ustawione przypomnienie można usunąć tym samym miejscem.

Listy M3U

  1. Ustawienia → Dodaj listę.
  2. Rodzaj: Adres listy M3U (nazwa + adres http://…) albo Xtream Codes (serwer http://serwer:port, login, hasło).
  3. Dodaj. Lista pobiera się na dekoder. Aktywną listę wybierasz na stronie Start, w karcie Listy M3U.

Plik z komputera: Wgraj plik .m3u z komputera. Automatyczne pobieranie aktywnej listy raz na dobę włącza się na stronie Start, w karcie Automatyczne pobieranie. Aktywną listę można zmienić także na TV: Listy M3U na ekranie startowym.

13. Ustawienia

1. What the plugin is

HPL ink IPTV is a plugin for satellite set-top boxes running Enigma2. It plays channels, movies and series from IPTV lists, shows the TV guide and reminds you about programmes. Lists, the guide and settings are easiest to add from a computer or phone, in the browser panel.

  • M3U / M3U8 lists from a URL, from a file on your computer or from an Xtream Codes account (server, login, password).
  • TV channels in three columns: bouquets, channels and a card with the current programme.
  • Its own player with OSD, channel list, tile strip, reminders and automatic recovery of a stopped picture.
  • Movies with a poster wall, series with the next episode, resuming from where you stopped.
  • XMLTV guide with automatic import, guide search, reminders with a choice of „Remind” or „Switch”.
  • Favourites, history, a „Watch later” list, Polish and English language.
Network: the box, computer and phone must be in the same home network. The panel is not a website on the internet — it works only at home, at the address shown on the TV.

Other boxes and images: the plugin is written in pure Python and uses standard Enigma2 components.   • An IPTV list from your provider: an M3U address, an M3U file or Xtream Codes account details.

  • The python3-sqlite3 Python module — included in the OpenBH 5.x image, on OpenBH 6.0 it must be installed (chapter 3).

3. Installation

1. FileCopy enigma2-plugin-extensions-hpliptv_2.01_all.ipk to the /tmp folder on the box (FTP / SFTP).
2. InstallLog in to the box over Telnet / SSH and enter the install command (below).
3. Restart GUIRestart the interface: Menu → Standby / Restart → Restart GUI.
4. StartThe plugin is in Menu → Plugins and in the extensions menu (Extensions) as HPL ink IPTV.

Install command:

opkg install /tmp/enigma2-plugin-extensions-hpliptv_2.01_all.ipk

Updating to a newer version works the same way — the new package replaces the old one, settings and lists stay. Uninstall: opkg remove enigma2-plugin-extensions-hpliptv.

OpenBH 6.0 — an additional package is required. The OpenBH 6.0 image does not include the Python database module in which the plugin stores the EPG guide. Without it the EPG import ends with the message „The sqlite3 module is missing - EPG has nowhere to be saved”. After installing the plugin, before the first EPG import, enter over Telnet / SSH:

opkg update && opkg install python3-sqlite3

and restart the GUI. In OpenBH 5.x this package is already in the image — nothing needs to be installed. To check whether the package is present: opkg list-installed | grep python3-sqlite3.

exteplayer3 player (optional)

By default the plugin plays through GStreamer (4097), which every image has. The second player, exteplayer3 (5002), is sometimes better with high-bitrate channels. It needs the ServiceApp plugin from your image's repository:

opkg update && opkg install enigma2-plugin-systemplugins-serviceapp

After restarting the GUI choose Player: exteplayer3 (5002) in the plugin Settings. When ServiceApp is not installed, the plugin plays through GStreamer on its own and says so in a message.

ServiceApp must match the system. Install it only from the repository of the same image you have on the box. A package from another image or an older archive may fail to load and give a black screen on exteplayer3.

4. First start

On the first start the plugin has no list yet. The simplest way is to add one through the browser panel.

  1. In the plugin choose Web panel (PC) TV. The screen shows the panel address, e.g. http://192.168.1.50:8098, a QR code and an access key.
  2. Open this address in a computer browser or scan the QR code with a phone PANEL.
  3. In the panel go to Settings → Add list (or the Add list button on the Home page) and enter the list address or the Xtream Codes details. A file from your computer is added in the same place: Upload an .m3u file from the computer.
  4. The list downloads to the box. Go back to the plugin on the TV — channels, movies and series are ready.
  5. The EPG guide downloads on its own („Auto PL” source). It can also be imported right away: EPG and reminders → Import TV EPG.
Without a computer: the list address can also be entered on the TV, in Settings and tools → Settings → Source 1, with the YELLOW key (edit), then choose Refresh M3U list.

10. EPG and reminders

EPG guide

The plugin uses a guide in XMLTV format. The source is chosen in Settings:

  • Auto PL (default) — a set of Polish guides from the internet.
  • url-tvg from the M3U list — the guide address stored in the list itself.
  • Own XMLTV URL (EPG custom URL) — any address of an .xml or .xml.gz file.

With an Xtream Codes list the guide is set automatically from the Xtream server when the list gives no address of its own. The import runs automatically every 48 hours and does not disturb watching — while something is playing, it waits. Manually: EPG and reminders → Import TV EPG.

EPG matching

When a channel has no schedule while others do, assign the right guide channel to it: EPG and reminders → EPG matching. OK assigns, BLUE filters by name, YELLOW deletes the assignment. The same can be done in the panel, in Settings → EPG guide → EPG matching.

Reminders

A reminder is set on a future programme: in the channel guide, in the guide search results, in the channel menu, in the player menu or in the panel. Every reminder has a type:

14. Troubleshooting

Message „The sqlite3 module is missing - EPG has nowhere to be saved”

The python3-sqlite3 package is missing — this concerns OpenBH 6.0. Enter opkg update && opkg install python3-sqlite3, restart the GUI and run the EPG import again (chapter 3).

The list is empty

Check the list address in the panel and choose Refresh M3U list. An Xtream list needs a correct server address with the port, login and password.

No EPG

Run Import TV EPG and wait for the completion message. When the import fails, change the EPG source or enter your own XMLTV address.

One channel has no schedule while the rest do

Assign a guide channel to it in EPG matching (chapter 10).

Black screen on exteplayer3 (5002)

Most often ServiceApp is not installed or does not match the system. Set Player: GStreamer (4097). Open Menu → Plugins — if Enigma shows the „Some plugins are not available” window with ServiceApp, install ServiceApp from your image's repository (chapter 3).

The picture freezes or a channel does not respond

The plugin tries to restore the picture by itself (chapter 7). When the problem returns on the same channels, try the other player (4097 ↔ 5002) and check the box's network connection — preferably wired.

The panel does not open

Check that the panel is switched on (Settings → Web panel (PC)), that the computer is in the same network and that the address is copied exactly. Restarting the box GUI also helps.

The plugin does not start after installation

Restart the GUI. Make sure the system uses Python 3 (Python 3.12 or 3.14, chapter 2) — this version does not work on images with Python 2.7.
