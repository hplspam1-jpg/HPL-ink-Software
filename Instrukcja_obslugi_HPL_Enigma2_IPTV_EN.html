2. Program activation PRIVE ONLY

The PRIVE TV edition requires a license activated for one specific computer. Until a valid activation code is entered, the main window does not start — only the Program activation required dialog appears. This dialog is in English.

Step by step

1. Request codeSelect Copy code in the activation window to copy the request code.
2. Send itSend the copied code to hplink.soft@proton.me.
3. SubjectUse the full program name as the message subject, for example HPL ink Enigma2+ IPTV PRIVE TV v4.38.
4. Activation codePaste the code you receive into Activation code and select Activate.

A successful activation shows Activation completed. The program will start normally. and the program continues to its normal startup. Later sessions do not repeat the activation.

Computer ID

The window displays a short identifier in the form HPL-XXXX-XXXX-XXXX, derived from the Windows machine identifier, the BIOS/UEFI serial number and the first detected MAC address. A license is bound to that combination, so an activation code issued for one computer will not work on another.

License scope

  • The activation code is cryptographically signed and verified locally, without an internet connection.
  • A license can be perpetual or valid until a given date. After it expires, the activation window appears again.
  • The license state is stored in parallel in the user registry and in three hidden helper files, encrypted and integrity-checked.
  • System clock rollback is detected; the tolerance is two minutes.
Important: editing or deleting the license data manually is detected as tampering and locks the program again. Replacing the mainboard or network adapter, or reinstalling Windows, can change the computer ID and require a new activation code.

3. Startup and initial configuration

Requirements

  • 64-bit Windows 11.
  • An Enigma2 receiver with OpenWebif enabled, on the same network as the PC.
  • An M3U/M3U8 playlist when IPTV is required.
  • 64-bit VLC when the external VLC button or functions requesting its location are used.
  • A TMDb API key for movie/series details and posters. PRO + ULTRA Create or sign in to a TMDb account, open Account settings → API on a desktop browser, accept the terms and request a developer key. Official guide: TMDb Getting Started.

Portable operation

  1. Extract the complete program folder. Do not move the EXE away from its libraries and subfolders.
  2. Run HplEnigma2IptvWinUI.exe.
  3. If the application folder is writable, data is stored next to the EXE. Otherwise, the program uses %LocalAppData%\HplEnigma2Iptv.
  4. In PRIVE, Tools → Portable data manager reports the current mode, the data folder and the SQLite database size, and exports or imports the complete data set. PRIVE ONLY
PRIVE: the license must be activated before the main window opens — see chapter 2. Program activation. License data is not kept in the program folder, so copying a portable folder to another computer does not transfer the activation. PRIVE ONLY

Connecting to Enigma2

1. IPEnter the receiver address on the local network.
2. USER/PASSEnter OpenWebif credentials when authentication is enabled.
3. PORT/WEBTypical values are stream 8001 and OpenWebif 80.
4. SaveSave the configuration and select Bouquets.

Locate VLC selects the VLC executable. VLC opens the current stream in the external player and is useful for diagnostics.

5. Enigma2

Loading and playing channels

  1. Complete the connection fields and select Save.
  2. Select Bouquets. Red bold entries represent bouquets/folders.
  3. Select a bouquet and double-click a channel.
  4. Current and next EPG appears below the video when the receiver supplies it.

The channel context menu provides Play, Add to favourites, Show EPG and Copy URL. The bouquet context menu loads the bouquet or copies its service reference.

Remote control

Remote opens the virtual Enigma2 remote, including navigation, number, media and REC keys. Commands are sent through OpenWebif.

Enigma2 reconnect PRO + ULTRA

After a stream failure, the program attempts to resume playback. Manual Stop prevents reconnect for the stopped channel. The function can be disabled in Settings.

Channel picons ULTRA ONLY

Picons appear in the E2 list and above the player. They can be placed in Picon\Enigma2 next to the EXE or downloaded from the receiver with Picon manager.

Signal strength ULTRA ONLY

Select Tools → Signal strength. The window shows SNR, SNR dB, AGC, BER and lock state for the current E2 service, refreshing every two seconds.

EPG in the channel list PRIVE ONLY

The Enigma2 channel list shows the current programme title in neon green. Data is fetched for the whole bouquet once it is selected and refreshed automatically every 60 seconds.

Enigma2 tuner panel PRIVE ONLY

Select Tools → Enigma2 tuner panel. The window reports receiver tuner status with the time of the last update and a Refresh button. If the receiver exposes no tuner data, a message is displayed instead.

COMPATIBILITY mode PRIVE ONLY

COMPATIBILITY is intended for computers where Enigma2 produced audio without video. The picture is then rendered in a native VLC window (HWND) with software decoding, bypassing the WinUI VideoView and Direct3D11 path.

  • AUTO (GPU → COMPATIBILITY) starts with GPU and switches the machine to compatibility mode when no frames are displayed.
  • The working mode is stored in the computer profile and reused on later startups.
  • In the normal GUI view the native video window is clipped to the EPG panel and does not cover it. VIDEO and Cinema modes use the full player area.
  • Tools → Playback parameters reports which path is actually rendering the picture.

6. IPTV and M3U playlists

Loading a playlist

  1. Select M3U and open an .m3u or .m3u8 file.
  2. Groups appear in the IPTV panel. All displays all live TV channels.
  3. Select a group and double-click a channel.
  4. IPTV opens in a separate window and can run concurrently with Enigma2.
Privacy: loading or browsing a playlist does not open every stream URL. A provider connection is made when a selected item is played or a referenced resource such as a logo is fetched.

M3U editor

M3U Ed. edits channel name, group, URL and logo. Auto logo assigns available graphics. PRO and ULTRA can rebuild the editable list from the currently loaded playlist. PRO + ULTRA

Custom group order PRO + ULTRA

Right-click a group and choose Move up or Move down. All remains pinned at the top.

IPTV player

The window includes Pause/Play, Stop, Video, Cinema, volume control, current EPG and a channel logo when available. Closing IPTV does not close the main program.

IPTV reconnect ULTRA ONLY

Live channels receive up to three reconnect attempts at five-second intervals. VOD movies and series are not restarted after their natural end.

IPTV provider profiles PRIVE ONLY

Select Tools → IPTV provider profiles. A profile pairs an M3U playlist with its EPG file, so switching providers no longer requires picking files again.

  1. Add — create a profile and give it a name.
  2. Add M3U — select the playlist for this profile.
  3. Select EPG — assign the EPG file or address.
  4. Set active — mark the profile as the default one.
  5. Load profile — immediately load the channels and EPG of the selected profile.

Profiles, M3U channels, EPG and history are kept in the SQLite database hpl_media.db, which speeds up loading of large playlists.

Alternate channel sources PRIVE ONLY

Right-click an IPTV channel and choose Alternate sources. A channel can hold several backup addresses, each with its own name and priority.

  • Add stores a new source; an invalid URL is rejected with a message.
  • Play selected starts a chosen source manually.
  • A watchdog detects missing video or stalled data and switches the channel to the next source by priority.
  • After a switch the player shows the Alternate source status without changing the channel name. When nothing responds, the status becomes No working source.

Channel logos PRIVE ONLY

An IPTV channel logo is selected in this order: EPG/XMLTV icon → tvg-logo from the M3U playlist → local logo folder. The order applies both to the channel list and to the playback window. EPG shown next to M3U channels uses neon blue #00d4ff.

IPTV player in PRIVE PRIVE ONLY

The IPTV window uses a black HUD drawn over the picture. The top area shows the logo, channel name, playback state and a clock; the bottom area shows NOW ON AIR and UP NEXT EPG, a progress bar and the full control set. The HUD hides three seconds after playback starts and returns on mouse movement.

8. EPG

EPG XML

EPG XML loads a local XMLTV file. Gzip-compressed data is also supported. Entries are matched to IPTV channel names.

Download EPG

Download EPG opens the download window. Enter the source address and destination, normally epg.xml. “Valid until” reflects the actual final programme in the data.

Bouquet EPG

Select an Enigma2 bouquet first, then Bouquet EPG. The window displays programmes for channels in that bouquet.

PRIVE: Bouquet EPG has been replaced by two guides — Enigma2 EPG and IPTV EPG — described below. PRIVE ONLY

Enigma2 EPG and IPTV EPG guides PRIVE ONLY

Both windows share the same layout, open at the size of the main GUI on the right-hand side of the desktop and use fonts one step larger.

  • The left column lists Bouquets (Enigma2) or Groups (IPTV). The memory-heavy “All” entry has been removed.
  • Each channel shows its picon, list position, NOW and NEXT programmes, a description and a progress bar. Current programme times are displayed in neon yellow.
  • The Search channel box filters by part of the name and the favourites only switch limits the view to favourites.
  • ◀ earlier, ▶ NOW and later ▶ shift the timeline.
  • Selecting a channel opens Channel EPG with the full schedule and programme descriptions.
  • Play starts the channel using the rules of its source. Record is available in the Enigma2 guide only.

EPG source profiles PRIVE ONLY

The Download EPG window has been extended into EPG sources and mapping. Select a ready Source profile or enter a Custom URL (.xml / .gz) and use Download and validate.

  • A new file is parsed and checked before it replaces a working epg.xml.
  • When a source fails, the program moves on to the next backup source in the profile.
  • EPG validity is calculated from actual programme dates and channel coverage. The status distinguishes current, expiring, expired and unconfigured data.
  • Expired EPG is downloaded automatically when a URL has been saved.
  • XMLTV time zones, including +HHMM offsets and UTC, are supported, as are gzip files regardless of their extension.

EPG mapping report PRIVE ONLY

Mapping report opens the M3U-to-XMLTV channel matching overview. The program uses tvg-id, tvg-name, aliases and cautious similar-name matching in that order, and caches the result in epg_mapping.json. The report lists matched, ambiguous and missing entries, with Rebuild mapping and Copy report available.

Record from EPG PRO + ULTRA

Use Record for the selected programme. Depending on the command and window, the program creates an Enigma2 timer or starts a local recording.

EPG reminders PRO + ULTRA

Enable reminders in Settings, select 5-15 minutes, optionally restrict to Favourites and enter comma-separated keywords.

9. Recording and timeshift

Record and recording schedule PRO + ULTRA

Record saves the current Enigma2 stream in Recorded next to the EXE. Press Record again or Stop to finish. The schedule window reads Enigma2 timers and requires receiver confirmation when deleting one.

Recording library ULTRA ONLY

Tools → Recording library lists TS, MP4, MKV and AVI files in Recorded. It supports playback, rename, delete, size and date information.

Recording monitor ULTRA ONLY

Displays elapsed time, file size, write speed and free disk space.

Timeshift ULTRA ONLY

  1. Start an Enigma2 channel and select Timeshift.
  2. The live stream is buffered to a temporary file.
  3. Pause and seek within the available buffer.
  4. Return to LIVE or stop timeshift. The temporary file is removed.

Advanced EPG recording PRIVE ONLY

Select Tools → Advanced EPG recording. The window defines rules that search the EPG on their own and schedule recordings on the receiver.

  1. Rule name — any description that identifies the rule in the list.
  2. Title keyword or phrase — a required field compared against programme titles.
  3. Channel (optional) — restricts the rule to a single channel.
  4. Lead margin (min) and Tail margin (min) — extra recording time before and after the programme.
  5. Rule enabled — includes the rule in scanning.
  6. Do not record the same title again — skips repeats already scheduled or recorded.
  7. Save rule, then Scan EPG and schedule.

After scanning, a report lists Matched programmes, Added to schedule, Skipped as duplicates and Errors. Receiver schedule opens the Enigma2 timer list. Scanning requires an enabled rule and a loaded Enigma2 bouquet.

Notifications and recording protection PRIVE ONLY

  • Windows 11 notifications report the start and end of a recording. They can be disabled in Settings.
  • Recording checks free disk space and shows the projected file size.
  • Closing the program during a local recording requires confirmation and warns that receiver timers may keep recording.

10. Playback and video modes

VIDEO

In the main window, VIDEO enlarges the Enigma2 video area and hides control panels. ULTRA requires an active E2 channel and displays a message otherwise. ULTRA ONLY: no-source guard

Cinema / F11

Enters full screen. Esc returns to the GUI and restores the default window size.

PiP

Opens a small MiniPlayer window. Closing PiP does not close the application.

Tracks

Displays VLC audio and subtitle tracks available for the current item. The active track is highlighted.

Audio

Audio-only mode hides video while keeping sound, for example for radio services.

Stop

Stops Enigma2 in the main window. Stop in IPTV affects only the IPTV window. In PRIVE, stopping runs off the UI thread with a timeout, so a stalled player cannot block the program — it is detached and a new VLC instance is created.

Video and Cinema modes in PRIVE PRIVE ONLY

The Enigma2 VIDEO and Cinema modes match the IPTV window one to one.

  • The top HUD shows the picon, channel name, playback state and a clock.
  • The bottom HUD shows EPG, a progress bar and the full player control set: Pause, 15-second seek, Stop, Restart, Mute, volume, aspect ratio, A/V and technical information.
  • The OSD hides after three idle seconds and returns on cursor movement — including over the native VLC surface in COMPATIBILITY mode.
  • The picture scales with the window, and the former Enigma2 bar and GUI status bar are hidden in this mode.
  • VIDEO and Cinema require an active Enigma2 channel; without a source the program shows a message and keeps the full GUI.

11. TV mode and phone remote PRIVE ONLY

TV mode

Select Tools → TV mode. The picture plays directly in a full-screen VLC window, while the channel list and controls act as an overlay.

  • The mode starts the current channel as soon as it opens.
  • The overlay provides a Search channels box, a Channels list and the Play and Hide buttons.
  • A separate button shows or hides the whole control overlay.
  • The mode closes automatically when Video or Cinema is selected, playback is stopped, or another channel is started in the main window.

Phone remote

Select Tools → Phone remote. The program starts a local HTTP server on the LAN so a phone browser can act as a remote control.

  1. Set the Port and select Start.
  2. The window shows the page address and a locally generated QR code. Copy address places the address on the clipboard.
  3. Open the address on the phone and enter the PIN.
  4. Authorisation is kept in a random, expiring HTTP-only session, so the PIN is not requested for every command.
Security: the remote works on the local network only. Do not expose its port to the internet and stop the server when it is not needed — the window then reports Server stopped.

14. Settings - every option from top to bottom PRO + ULTRA

Select Settings in the upper-right corner. The controls appear in the following order from the top. Scroll vertically and select Save settings when finished.

  1. Language and theme.
    • Interface language - select Polski (PL) or English (EN). Restart the program to apply it.
    • GUI theme - Black (classic) or Futuristic HUD. Restart to apply the new appearance.
  2. This computer profile. PRIVE ONLY
    • Automatically apply device profile - the program uses the settings stored for this specific computer at startup.
    • Decoding for this computer - AUTO (GPU → COMPATIBILITY), GPU, CPU or COMPATIBILITY.
    • Network profile and Playback buffer (ms) - transport settings for this computer.
    • GUI scale, Window width and Window height - interface size and scale; they take effect after a restart.
    • Startup volume - the audio level applied when the program starts.
  3. Startup profile.
    • Auto-connect to receiver - automatically uses the active Enigma2 receiver after startup.
    • Play last channel - attempts to resume the most recently watched item.
    • Restore last session and open tools - restores the Video mode, volume and tool windows from the previous session. PRIVE ONLY
    • Window at startup - None, Streaming Canal+/Polsat, Remote control or Download EPG.
    • Network quality preset - LAN uses the smallest buffer, WiFi a medium buffer and Mobile the largest, safest buffer for weaker connections.
    • Network/live buffer (ms) - range 150-10000 ms. A larger value usually reduces interruptions but increases startup time and live delay.
    • Automatically adapt buffer to stream quality - enables the adaptive buffer. Minimum buffer (ms) and Maximum buffer (ms) set the range and Current buffer shows the value in use. PRIVE ONLY
  4. EPG reminders.
    • Enabled - turns programme reminders on.
    • Minutes before the programme - select 5 to 15 minutes.
    • Favourites only - limits reminders to favourite channels.
    • EPG keywords - enter comma-separated phrases, for example movie, match, news. The programme title and channel name are checked.
  5. Automatic updates. PRIVE ONLY
    • Enable automatic background refresh - a scheduler refreshes data without user interaction.
    • Interval (minutes) - how often the refresh runs.
    • Refresh scope: EPG XMLTV, M3U playlist from the last selected file, Enigma2 bouquets and Missing Enigma2 picons.
    • The refresh uses only previously saved sources and never opens file picker windows.
  6. Cache storage. PRIVE ONLY
    • Automatically clean cache once a day - enables daily housekeeping of temporary data.
    • Poster limit (MB) - maximum size of the IPTV Movies / Series poster cache.
    • Diagnostic bundle limit (MB) - maximum size of the ZIP bundle folder.
    • Log retention (days) - after how many days logs are removed.
    • Clean now - immediate housekeeping; the program reports the number of deleted files.
  7. Playback and notifications. PRIVE ONLY
    • Windows 11 notifications - system messages about recordings and playback events.
  8. Parental lock.
    • Enabled - activates access control.
    • New PIN - enter at least four digits and select Set PIN.
    • Locked M3U groups - enter exact IPTV group names separated by commas.
    • Locked Enigma2 bouquets - enter exact E2 bouquet names separated by commas.
  9. Backup.
    • Backup .hplbackup - enter a password of at least four characters and choose where to save the encrypted configuration backup.
    • Restore backup - enter the password and select an .hplbackup file. A wrong password or damaged file displays an error instead of closing the program.

17. Troubleshooting

Bouquets and EPG work, but Enigma2 has audio only

  1. Test the same stream with the VLC button.
  2. Check the stream port, usually 8001, and WEB port, usually 80.
  3. In PRO, use the alternative GPU/CPU build. PRO
  4. In ULTRA, select AUTO or CPU decoding and reset the saved AUTO choice. ULTRA ONLY
  5. In PRIVE, select the COMPATIBILITY mode or run Tools → Computer compatibility wizard and choose Apply recommendations. PRIVE ONLY
  6. Select a larger buffer preset when sound or video is interrupted.

Live IPTV works, but a movie does not

Test the URL in VLC, verify account validity and concurrent connection limits. VOD uses LibVLC while live channels may use another playback engine.

Posters are missing

Check the TMDb key, internet connection and cleaned title. Open the movie folder and select Download posters.

DLNA or Chromecast is not found

The PC and device must be on the same network. Temporarily disable VPN, check Wi-Fi client isolation and allow private-network firewall access.

Temporary directory warning

“Failed to remove temporary directory” usually comes from an installer or updater. Close processes using TEMP, restart Windows and delete only the specified unused temporary folder.

Settings are not stored next to the EXE

Move the program to a user-writable folder or check %LocalAppData%\HplEnigma2Iptv. In PRIVE, Tools → Portable data manager reports the current mode.

The program asks for activation again PRIVE ONLY

  1. Check whether the system date and time have been moved backwards.
  2. Check whether hardware affecting the computer ID has changed — mainboard, system disk or network adapter.
  3. Registry and temporary-file cleaners can delete the license data. Compare the identifier in the activation window with the previous one.
  4. If the identifier is unchanged, send a new request code to the address shown in the activation window.

An IPTV channel switches to another source PRIVE ONLY

The Alternate source status means the watchdog detected missing video or stalled data and moved to a backup source. Edit the list and priorities from the channel context menu → Alternate sources. No working source means no address responded.

EPG does not match IPTV channels PRIVE ONLY

Open Download EPG → Mapping report. Review the ambiguous and missing entries, correct channel names in the M3U editor or add an alias, then select Rebuild mapping.
