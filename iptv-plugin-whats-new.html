HPL ink IPTV

What's new compared to the earlier free version.Co nowego w porównaniu z wcześniejszą darmową wersją.

ActivationAktywacja

  • The plugin requires a one-time activation for each receiver. After installation it shows the device ID and a request code. You send the code by e-mail and receive an activation code in reply, which you paste in the web panel. The code works only on that receiver. After reinstalling on the same receiver you can use it again.Plugin wymaga jednorazowej aktywacji dla danego dekodera. Po instalacji wyświetla identyfikator urządzenia i kod żądania. Kod wysyłasz e-mailem, a w odpowiedzi dostajesz kod aktywacji, który wklejasz w panelu WWW. Kod działa tylko na tym dekoderze. Po ponownej instalacji na tym samym dekoderze możesz użyć go jeszcze raz.
  • The new version installs as a separate plugin and does not replace the free version. On first launch it imports its playlists, favourites, reminders and settings.Nowa wersja instaluje się jako osobny plugin i nie zastępuje wersji darmowej. Przy pierwszym uruchomieniu przejmuje z niej listy, ulubione, przypomnienia i ustawienia.
  • The web panel runs at a new address: http://receiver-IP:8099 (the plugin shows the exact address).Panel WWW działa pod nowym adresem: http://IP-dekodera:8099 (dokładny adres pokazuje plugin).

PlaybackOdtwarzanie

  • A third player to choose from: GStreamer with ServiceApp, alongside Enigma's GStreamer and exteplayer3.Trzeci odtwarzacz do wyboru: GStreamer z ServiceApp, obok GStreamera Enigmy i exteplayer3.
  • Adjustable GStreamer (ServiceApp) buffer size and time, helpful when the picture stutters.Ustawienie rozmiaru i czasu bufora GStreamera (ServiceApp), pomocne przy rwącym się obrazie.
  • A per-channel player: a channel that stutters on one player can be permanently assigned to another (MENU while watching or MENU in the channel list). When a channel's picture freezes often, the plugin suggests switching the player.Własny odtwarzacz dla wybranego kanału: kanał, który na jednym odtwarzaczu się zacina, możesz na stałe przypisać do innego (MENU podczas oglądania albo MENU na liście kanałów). Gdy obraz kanału często staje, plugin sam podpowiada zmianę odtwarzacza.
  • Faster detection of a frozen picture: the plugin recognises that the player has stopped receiving data even though the playback clock keeps running, and restarts the channel after a dozen or so seconds rather than after a few minutes.Szybsze wykrywanie zawieszonego obrazu: plugin rozpoznaje, że odtwarzacz przestał pobierać dane, choć zegar odtwarzania wciąż biegnie, i sam wznawia kanał po kilkunastu, a nie po kilku minutach.
  • Gentler recovery: successive attempts to restart the channel at increasing intervals. When the attempts are exhausted and there is no backup source, the plugin shows a message instead of restarting endlessly.Spokojniejsze wznawianie: kolejne próby ponownego uruchomienia kanału w rosnących odstępach. Gdy próby się wyczerpią, a nie ma łącza zapasowego, plugin pokazuje komunikat zamiast restartować bez końca.
  • More accurate checking of whether ServiceApp actually works (previously the mere presence of the plugin was enough). When exteplayer3 is selected but ServiceApp hasn't loaded, the channel plays through GStreamer with a message instead of a black screen.Dokładniejsze sprawdzanie, czy ServiceApp naprawdę działa (dawniej wystarczyła sama obecność wtyczki). Gdy wybrany jest exteplayer3, a ServiceApp się nie wczytał, kanał gra przez GStreamer z komunikatem zamiast czarnego ekranu.
  • Lighter downloading of posters and logos (fewer simultaneous downloads, a size limit): less load on the receiver.Lżejsze pobieranie plakatów i logo (mniej równoczesnych pobrań, limit rozmiaru): mniejsze obciążenie dekodera.
  • Channel selection by number from the remote, in the player and in the channel list.Wybór kanału numerem z pilota, w odtwarzaczu i na liście kanałów.
  • Startup option: on opening the plugin it immediately plays the last-watched channel.Opcja startu: po otwarciu pluginu od razu gra ostatnio oglądany kanał.
  • In the player MENU, “Save a problem report”: saves technical data from the last few minutes when something goes wrong.W MENU odtwarzacza „Zapisz raport z problemu”: zapisuje dane techniczne z ostatnich minut, gdy coś działa źle.

RecordingNagrywanie

  • Recording programmes from the EPG guide (BLUE in the channel guide, MENU in the player, or the “Record” button in the web panel). The plugin records even when it is closed.Nagrywanie audycji z przewodnika EPG (NIEBIESKI w przewodniku kanału, MENU w odtwarzaczu albo przycisk „Nagraj” w panelu WWW). Plugin nagrywa także wtedy, gdy jest zamknięty.
  • Recordings go to the receiver's disk (/media/hdd/movie) and are visible in the plugin (EPG and reminders - Recordings) and in the receiver's recordings list.Nagrania trafiają na dysk dekodera (/media/hdd/movie), są widoczne w pluginie (EPG i przypomnienia - Nagrania) i na liście nagrań dekodera.
  • Note: many IPTV providers allow only one connection at a time. Watching another channel during a recording may interrupt it. HLS streams (.m3u8) are not recorded.Uwaga: wielu dostawców IPTV pozwala tylko na jedno połączenie naraz. Oglądanie innego kanału w trakcie nagrywania może je przerwać. Strumienie HLS (.m3u8) nie są nagrywane.

PIN lockBlokada PIN

  • Selected channel bouquets can be locked with a 4-digit PIN (MENU on a channel - Lock bouquet with PIN). A locked bouquet opens only after entering the PIN, and its channels are hidden from search and favourites.Wybrane bukiety kanałów można zablokować 4-cyfrowym PIN-em (MENU na kanale - Zablokuj bukiet PIN-em). Zablokowany bukiet otwiera się dopiero po wpisaniu PIN-u, a jego kanałów nie widać w wyszukiwaniu ani w ulubionych.
  • You can set or change the PIN in the web panel too, including when you've forgotten it.PIN ustawisz albo zmienisz także w panelu WWW, również wtedy, gdy wypadł z pamięci.

Appearance (OSD & menus)Wygląd (OSD i menu)

  • A new bottom OSD bar:Nowy dolny pasek OSD:
    • programme progress;postęp audycji;
    • a full line with the next programme;pełna linia z następną audycją;
    • stream parameters (resolution, codec, audio, subtitles);parametry strumienia (rozdzielczość, kodek, dźwięk, napisy);
    • the name of the active playlist and the player currently in use;nazwa aktywnej listy i odtwarzacza, który właśnie gra;
    • remote-key hints.podpowiedzi klawiszy pilota.
  • In menus that don't fit on screen, a note “N more items below / above” and the item number appear under the list, so no option is missed.W menu, które nie mieszczą się w oknie, pod listą widać informację „jeszcze N pozycji niżej / wyżej” i numer pozycji, więc żadna opcja nie umknie.
  • A custom plugin icon in the plugin list.Własna ikona pluginu na liście wtyczek.

Web panelPanel WWW

  • One-click backup: playlists (including those uploaded from a computer), favourites, history, reminders, settings, manual EPG matches. Restore from a file, e.g. after flashing new receiver software.Kopia zapasowa jednym kliknięciem: listy (także wgrane z komputera), ulubione, historia, przypomnienia, ustawienia, ręczne dopasowania EPG. Przywracanie z pliku, np. po wgraniu nowego oprogramowania dekodera.
  • Install a new plugin version straight from the panel (an .ipk file from your computer), with no terminal, plus a “Restart GUI” button.Instalacja nowej wersji pluginu prosto z panelu (plik .ipk z komputera), bez terminala, i przycisk „Restart GUI”.
  • TV bar: the next programme on a separate, clear line.Pasek telewizora: następna audycja w osobnym, czytelnym wierszu.
  • New settings: GStreamer ServiceApp player, buffer, start with the last channel, PIN lock.Nowe ustawienia: odtwarzacz GStreamer ServiceApp, bufor, start z ostatnim kanałem, blokada PIN.

Requirements & compatibilityWymagania i zgodność

  • OpenBH 5.x and 6.0 (Python 3). On OpenBH 6.0 the required python3-sqlite3 module is installed together with the plugin (run opkg update before installing from a file).OpenBH 5.x i 6.0 (Python 3). Na OpenBH 6.0 potrzebny moduł python3-sqlite3 instaluje się razem z pluginem (przed instalacją z pliku wykonaj opkg update).
  • The version for OpenATV 6.1 (Python 2.7) is no longer developed.Wersja dla OpenATV 6.1 (Python 2.7) nie jest już rozwijana.
