1. Czym jest program

HPL IPTV E2+ Radio to aplikacja na telewizor z Android TV. Odtwarza kanały IPTV, tunery Enigma2 i radio internetowe. Listy, EPG, filmy i ustawienia dodaje się z komputera albo telefonu przez panel w przeglądarce — ten sam komputer, na którym stoi program PC HPL ink Enigma2+ IPTV, albo dowolna inna przeglądarka w sieci domowej.

  • Playlista M3U / M3U8 z adresu URL.
  • Konto Xtream Codes (serwer, port, użytkownik, hasło).
  • Tuner Enigma2 z OpenWebif — bukiety, strumień i program z tunera.
  • Radio internetowe z playlisty M3U (adres albo plik z komputera).
  • Przewodnik XMLTV, filmy i seriale z playlisty, ulubione, historia, przypomnienia i kopia zapasowa.
Sieć: telewizor, komputer i telefon muszą być w tej samej sieci lokalnej. Panel i strona aktywacji nie są stroną internetową w sieci publicznej — działają tylko w domu, pod adresem pokazanym na TV.

2. Aktywacja programu

Przy pierwszym uruchomieniu program nie otwiera listy źródeł. Na telewizorze pojawia się wyłącznie ekran ACTIVATION REQUIRED. Ten ekran jest po angielsku. Do czasu wpisania prawidłowego kodu aktywacyjnego reszta programu pozostaje zamknięta.

Kod aktywacyjny z jednego telewizora nie zadziała na innym.

Najwygodniejsza droga — komputer

Kod aktywacyjny jest długi. Wklejenie go w przeglądarce na komputerze jest prostsze niż wpisywanie pilota na TV.

1. AdresNa TV odczytaj linię OPEN THIS ADDRESS ON A COMPUTER, np. http://192.168.1.50:8091/activate.
2. Request codeOtwórz adres w przeglądarce i wybierz Copy code.
3. WyślijWyślij skopiowany kod na hplink.soft@proton.me.
4. ActivateOtrzymany kod wklej w pole ACTIVATION CODE i wybierz Activate.

W temacie wiadomości wpisz dokładnie:

HPL IPTV E2+ Radio activation

Po poprawnej aktywacji strona pokazuje Activated. The program is starting on the TV. Telewizor sam przechodzi do zwykłego ekranu źródeł. Przy kolejnych startach ten ekran się nie pojawia.

Ta sama czynność na telewizorze

Gdy nie masz komputera pod ręką, te same pola są na ekranie TV:

  • DEVICE ID — krótki identyfikator w postaci HPL-XXXX-XXXX-XXXX.
  • REQUEST CODE — długi kod do wysłania.
  • Copy code — kopiuje request code (gdy telewizor ma schowek).
  • ACTIVATION CODE — pole na otrzymany kod.
  • Activate — zatwierdza kod.
  • Close program — zamyka aplikację.

Komunikat This code is not valid for this device. oznacza, że wklejony kod nie pasuje do tego telewizora. Sprawdź, czy wysłałeś request code właśnie z tego urządzenia i czy wkleiłeś cały otrzymany kod, bez obcięcia.

Pozostałe wersje programu: hplspam1-jpg.github.io/HPL-ink-Software

Sieć przy aktywacji: adres /activate działa tylko wtedy, gdy telewizor ma połączenie z siecią lokalną. Gdy TV pokazuje no network connection, podłącz Wi-Fi albo kabel i uruchom program ponownie.

3. Pierwsze uruchomienie

Wymagania

  • Telewizor albo dekoder z Android TV / Google TV, system Android 8.0 lub nowszy.
  • Ta sama sieć lokalna dla telewizora, komputera i telefonu.
  • Dla IPTV: playlista M3U/M3U8 albo dane Xtream Codes od dostawcy.
  • Dla Enigma2: tuner z włączonym OpenWebif w tej samej sieci.
  • Dla radia: playlista M3U pod adresem URL albo plik .m3u z komputera (najwyżej 6 MB).
  • Opcjonalnie klucz API TMDb v3 — wyłącznie do opisów, ocen i tytułu oryginalnego filmów. Plakaty biorą się z playlisty.

Po aktywacji

  1. Na TV zostaje ekran źródeł i duży adres panelu, np. http://192.168.1.50:8091/?token=….
  2. Skopiuj cały adres, razem z parametrem token.
  3. Otwórz go w przeglądarce na komputerze.
  4. W panelu, w Ustawieniach, dodaj pierwsze źródło.
  5. Wróć na telewizor i wejdź w to źródło, aby wczytać listę.
Ważne: adres bez token nie otworzy panelu. Przy dodawaniu drugiego telewizora wklejaj zawsze pełny adres z jego ekranu.

4. Ekran źródeł TV

To pierwszy ekran po aktywacji. Poniższy rysunek jest schematem GUI i nie zawiera prawdziwego adresu ani tokenu.

Ekran ma dwie kolumny. W nagłówku, przy prawej krawędzi, stoi zegar. Po lewej nagłówek TWOJE ŹRÓDŁA, lista, a pod nią jedna linia z adresem, datą przewodnika i wynikiem ostatniego testu — zawsze dla źródła, na którym stoi kursor. Karta po prawej pokazuje audycję z kanału, na którym stoi kursor: logo, tytuł, godziny, pasek postępu, opis i — pod spodem — NASTĘPNIE z godziną i tytułem kolejnej pozycji.

Pod nią stoi przycisk Przypomnij o następnej. Strzałka w prawo z dowolnego wiersza listy prowadzi wprost na niego, a w lewo wraca na ten sam kanał, z którego się wyszło. OK zakłada przypomnienie — napis zmienia się na ✔ Przypomnienie ustawione, a kolejne OK je zdejmuje. Przy kanale bez przewodnika przycisk jest przygaszony i mówi, czego brakuje. Przypomnienie powiadamia, nie przełącza kanału samo z siebie.

Dwa menu zamiast kolorowych klawiszy. Nad listą bukietów stoi pozycja ☰ Menu — wchodzisz na nią strzałką w górę z pierwszego bukietu, OK otwiera. W środku są rzeczy dotyczące całego ekranu: Import EPG, Odśwież listę, a przy tunerze także Nagrania z tunera. Rzeczy dotyczące jednego kanału — Przewodnik i Ulubione — siedzą pod przytrzymaniem OK na kanale, żeby było widać, czego dotyczą. Kolorowe klawisze z tabeli niżej dalej działają jako skróty.

W nagłówku, obok liczby kanałów, stoją przyciski Ustawienia oraz — zależnie od rodzaju źródła — Filmy przy playliście IPTV albo czerwone Nagrania przy tunerze Enigma2.

Nagrania z dysku tunera TV

Dekoder Enigma2 nagrywa na własny dysk. Program potrafi z niego korzystać — to nie są filmy z playlisty IPTV i nie mają nic wspólnego z zakładką Filmy.

Wejście jest w dwóch miejscach: przycisk Nagrania w nagłówku listy kanałów tunera albo ☰ Menu → Nagrania z tunera.

  • Ekran wygląda jak katalog na dekoderze: najpierw foldery, potem nagrania od najnowszych, przy każdym data, długość i kanał, z którego zostało nagrane.
  • OK wchodzi w folder albo odtwarza. WSTECZ cofa o katalog wyżej i stawia kursor tam, skąd się wyszło; z pierwszego katalogu wychodzi z ekranu.
  • Nagranie odtwarza się jak film: przewijanie działa, a koniec pliku kończy odtwarzanie.
  • Program zaczyna od katalogu wpisanego w polu Katalog nagrań przy źródle (rozdział 10); puste pole znaczy katalog domyślny dekodera.
Pusto nie znaczy „brak nagrań". Dekoder w stanie czuwania odpowiada pustą listą. Jeśli ekran mówi, że nagrań nie ma, a wiesz, że są — wybudź dekoder i wejdź ponownie.

6. Odtwarzacz TV

Kanał otwiera się na pełnym ekranie. OSD pokazuje logotyp kanału, jego nazwę na czerwono, tytuł audycji, godziny nadawania i pasek postępu. Znika po chwili i wraca po OK albo INFO — wywołane klawiszem stoi dwa razy dłużej niż to, które pokazuje się samo po zmianie kanału.

W dolnym wierszu OSD widać, z której playlisty leci obraz: napis IPTV i dwa pierwsze człony nazwy źródła, np. źródło „TV VOD 12.2026” daje IPTV TV VOD. Przy tunerze widnieje samo Enigma2. Obok stoi podpowiedź kolorowych klawiszy i pozycja OK dłużej — obraz.

Pasek kafelków — klawisz w prawo

Na kanale na żywo prawo wysuwa u dołu ekranu pasek kafelków. Każdy kafelek to logotyp kanału, jego nazwa i audycja, która właśnie na nim leci. Obraz gra dalej pod spodem.

  • Prawo / lewo przesuwa zaznaczenie. Przy otwartym pasku lewo nie otwiera listy kanałów.
  • OK włącza zaznaczony kanał, WSTECZ zamyka pasek.
  • Pasek chodzi po bieżącym bukiecie i zatrzymuje się na jego końcach. Po inne bukiety sięgnij listą pod klawiszem w lewo.
  • Otwarcie paska nie pobiera niczego z sieci — logotypy i program pochodzą z pamięci telewizora.
  • Góra pokazuje pełny opis audycji z kanału pod kursorem — nie z tego, który oglądasz. Oglądasz HBO, przejeżdżasz na Canal+ i klawiszem w górę czytasz, co leci na Canal+. To samo robi ŻÓŁTY. WSTECZ zamyka opis i wraca do paska, więc można przejrzeć kilka kanałów po kolei.

Kropka przypomnienia i zapowiedź audycji

  • Czerwona kropka pod zegarem w OSD znaczy, że czeka co najmniej jedno przypomnienie. Widać ją na każdym kanale i gaśnie dopiero wtedy, gdy ostatnie oczekujące przypomnienie się zrealizuje. Co dokładnie czeka, pokazuje panel na stronie Start.
  • Zapowiedź kolejnej audycji pojawia się w rogu ekranu na kilka minut przed jej startem. Wyprzedzenie ustawia się w panelu (rozdział 14), można ją też wyłączyć.
  • Uprzedzenie o przypomnieniu — na tej samej belce w rogu, na 5, 10, 15 albo 30 minut przed audycją, którą kazałeś sobie przypomnieć: Za 10 min · nazwa kanału i tytuł. Przy dłuższym wyprzedzeniu belka wisi dwadzieścia sekund zamiast dziesięciu. Wyprzedzenie ustawia się w panelu (rozdział 14), zero znaczy „bez uprzedzania".
  • Samo przypomnienie przychodzi minutę przed audycją — na tę samą belkę, w tej samej postaci, tylko zamiast „Za 10 min" pisze Teraz albo Przełączam, gdy przypomnienie ma od razu włączyć kanał.

Panel „Później" — trzy nadchodzące audycje

Na minutę przed końcem oglądanej audycji przy prawej krawędzi ekranu pojawia się na dziesięć sekund lista trzech kolejnych pozycji z programu tego kanału — godzina i tytuł. Pierwsza pozycja, czyli to, co zaraz się zacznie, jest wyróżniona.

  • OK albo WSTECZ zamyka panel od razu.
  • Panel można wyłączyć na stałe w ustawieniach panelu (rozdział 14).
  • Nic nie pobiera się przy tym z sieci — dane pochodzą z przewodnika zapisanego w telewizorze.
  • Zerwany strumień jest ponawiany kilka razy. Gdy w tym samym katalogu jest zapasowe łącze, program przełącza się na nie i pokazuje komunikat o innym łączu. Gdy zamiennika nie ma, mówi to wprost: brak zapasowego łącza dla tego kanału.
  • Pozycja filmu jest zapamiętywana. Przy ponownym otwarciu odtwarzanie wznawia się od tego miejsca.
  • Gdy obraz zamarza albo kanał nie odpowiada po kolejnych próbach, pojawia się komunikat z liczbą prób.
  • Minuta spokojnego obrazu kasuje pamięć nieudanych łączy — po chwilowym przeciążeniu sieci program znów ma dokąd się przełączyć.

Menu odtwarzacza — przytrzymanie OK

Przytrzymanie OK otwiera Menu odtwarzacza. Zbiera wszystko, co wcześniej wymagało kolorowych klawiszy:

  • Ścieżka audio — ta sama lista, co pod ZIELONYM.
  • Napisy — jak pod NIEBIESKIM; pozycja Wyłączone jest zawsze pierwsza.
  • Opis audycji — jak pod ŻÓŁTYM.
  • Poprzedni kanał — powrót na ostatnio oglądany, jak pod CZERWONYM.
  • Proporcje obrazu — opisane niżej.

Przy filmie menu ma trzy pozycje: film nie ma audycji do opisania ani poprzedniego kanału, na który można wrócić.

Gdy obraz stanie albo zniknie sieć

  • Obraz zamarł, a dźwięk leci dalej. Program liczy klatki faktycznie wyrysowane na ekranie. Gdy przez kilkanaście sekund nie przybywa żadna, pokazuje Wykryto brak obrazu. Przywracam obraz i sam odbudowuje połączenie. Wcześniej takie zamrożenie przechodziło niezauważone, bo licznik czasu rósł razem z dźwiękiem.
  • Zerwana sieć. Po utracie Wi-Fi albo restarcie routera na ekranie staje Brak sieci · czekam na połączenie. Program nie wypala wtedy prób i nie oznajmia padniętego kanału. Po powrocie sieci pokazuje Sieć wróciła · wznawiam odtwarzanie i sam wraca do obrazu — bez wychodzenia z kanału. Tak samo działa radio, a panel w przeglądarce podnosi się po zmianie adresu telewizora.

Źródło typu radio otwiera listę stacji, nie listę kanałów TV.

8. Program na telewizorze TV

Pełny harmonogram jednego kanału otwiera INFO na liście. Audycje są pogrupowane według dnia. OK na audycji pozwala oglądać kanał teraz albo ustawić przypomnienie. Przypomnienie może też przełączyć telewizor o godzinie startu.

Przewodnik odświeża się sam, raz na dobę. Nigdy w trakcie oglądania — zadanie czeka w kolejce i rusza, gdy nikt nie ogląda. Jeśli import już trwa, a Ty włączysz kanał, kończy się on na najbliższym kroku i wraca do kolejki. Telewizor wyłączony przez kilka dni nadrabia zaległość przy najbliższym uruchomieniu.

Ręcznie import XMLTV uruchamia się klawiszem ZIELONY na liście kanałów albo przyciskiem w panelu. Pobranie, dopasowanie nazw i zapis odbywają się na telewizorze, w tle, i mogą potrwać kilka minut. Tuner Enigma2 nie wymaga importu — program bierze z OpenWebif. Radio nie korzysta z telewizyjnego EPG.

Przerwany import nie kasuje już programu. Nowe audycje trafiają najpierw do zapasu, a stary przewodnik żyje do chwili, gdy cały plik zostanie poprawnie wczytany. Podmiana jest jednorazowa. Zerwana sieć albo uszkodzony plik XMLTV zostawia więc program taki, jaki był — a nie pusty albo połowiczny. Przy okazji importu program sprząta audycje starsze niż pół dnia i dalsze niż osiem dni.

Kanał, którego automat nie potrafi rozpoznać po nazwie, można przypisać do pozycji XMLTV ręcznie, z panelu — patrz rozdział 15.

Kilka telewizorów: jeden panel może sterować wieloma TV. Przełączenie telewizora zmienia też listy i program, bo każdy TV ma własne źródła.

Uruchamianie programu z komputera

Panel odpowiada tylko wtedy, gdy program działa na telewizorze. Serwer panelu żyje wewnątrz programu, więc przy zamkniętej aplikacji nie ma komu wydać polecenia — i właśnie dlatego uruchomienie z komputera wymaga sterowania IP samego telewizora, a nie naszego panelu.

Krok 1 — na telewizorze TV

  1. Naciśnij HOME i wejdź w Ustawienia.
  2. Odszukaj BRAVIA Settings → IP control. W części wydań ścieżka brzmi Sieć → Konfiguracja sieci domowej → IP control.
  3. Włącz sterowanie zdalne.
  4. Ustaw Uwierzytelnianie na klucz PSK i wpisz własny klucz, na przykład hpl. To hasło do sterowania telewizorem — nie używaj tu hasła, którego używasz gdzie indziej.

Krok 2 — w Programie PC

  1. W profilu telewizora wpisz ten sam klucz w polu Klucz PSK telewizora. Klucz jest szyfrowany dla bieżącego konta Windows, tak samo jak token panelu.
  2. Naciśnij Pobierz z TV — program pobierze listę aplikacji zainstalowanych na telewizorze.
  3. Wybierz z listy HPL IPTV E2+ Radio i zapisz profil. Wyboru dokonuje się raz; identyfikator aplikacji nie jest wpisany na sztywno, bo na jednym telewizorze może stać kilka odmian programu.
  4. Od tej chwili przycisk Uruchom program na telewizorze włącza aplikację bez sięgania po pilota.
Telewizor musi być włączony. Sterowanie IP nie budzi go ze stanu czuwania — przy wyłączonym odbiorniku przycisk zgłosi, że telewizor jest w czuwaniu. Komputer i telewizor muszą być w tej samej sieci domowej.
Po odcięciu telewizora od prądu ustawienie sterowania IP potrafi wrócić do stanu domyślnego. Jeśli przycisk przestanie działać, sprawdź najpierw Krok 1 — klucz PSK bywa wtedy do wpisania od nowa.

Wgranie nowej wersji z komputera

Przycisk Wyślij nową wersję na telewizor w Programie PC (od wersji 1.10) wgrywa wskazany plik .apk z dysku komputera, bez serwera i bez kabla. Komputer udostępnia plik na chwilę po sieci domowej i podaje telewizorowi jego adres — resztę robi już sam telewizor.

  • Aplikacja musi być otwarta na telewizorze; to ona przyjmuje polecenie. Jeśli jest zamknięta, najpierw Uruchom program na telewizorze.
  • Przed wysłaniem program pokazuje, jaka wersja stoi na telewizorze i jaka zostanie wgrana.
  • Telewizor sprawdza sumę kontrolną i podpis pakietu, a instalację i tak potwierdzasz pilotem — tak samo jak przy aktualizacji z adresu.
  • Przy pierwszym użyciu Windows może zapytać o zaporę: zezwól dla sieci prywatnej.

11. Filmy i seriale PANEL

Zakładki Filmy i Seriale pokazują pozycje, które playlista oznacza jako VOD (ścieżki albo metadane typu /movie/ i /series/). Plakaty biorą się z playlisty. Klucz TMDb w Ustawieniach dopisuje opis, ocenę i tytuł oryginalny dopiero po otwarciu pozycji.

  • Sortowanie: najnowsze, najstarsze, kolejność z playlisty, najwięcej odcinków (seriale).
  • Filtry: tylko z plakatem, do obejrzenia.
  • Znaczek ✚ na plakacie oznacza pozycję do obejrzenia.
  • W serialu: katalogi → serial → sezon → odcinek. Przycisk Następny nieobejrzany wznawia od pierwszego nieobejrzanego odcinka.
  • Play na telewizorze uruchamia materiał na wybranym TV.

Filtr VOD w Ustawieniach ukrywa te pozycje na zwykłej liście kanałów, żeby nie mieszały się z telewizją na żywo.

Pod uwagę brane są wyłącznie listy IPTV — playlisty M3U i Xtream. Tuner Enigma2 nie ma katalogu VOD, a rozpoznawanie po nazwach potrafiło brać za filmy zwykłe kanały w rodzaju „Polsat Seriale HD". Dlatego przy źródle tunera przycisk Filmów się nie pojawia; jego miejsce zajmują Nagrania. Panel i telewizor rozpoznają filmy tą samą regułą, więc lista w przeglądarce zgadza się z tym, co widać na ekranie.

Filmy na telewizorze TV

Ten sam katalog można otworzyć bez komputera: przycisk Filmy stoi na ekranie źródeł i w nagłówku listy kanałów. Ekran pokazuje siatkę plakatów, nad nią wybór katalogu, a pod spodem pełny tytuł zaznaczonej pozycji — na kafelku jest przycięty do dwóch wierszy.

  • Lista bierze się z pamięci telewizora: ekran nie łączy się z dostawcą. Gdy pamięć jest pusta, mówi to wprost, zamiast ściągać kilkadziesiąt megabajtów bez pytania.
  • OK odtwarza, WSTECZ wraca.

12. Pilot na telefonie PANEL

Kod QR jest w dwóch miejscach: w Ustawieniach panelu oraz — od wersji 2.16 — na ekranie źródeł na telewizorze, obok adresu panelu, z podpisem „PILOT NA TELEFONIE". Ten drugi jest ważniejszy, niż się wydaje: gdy komputer jest wyłączony, telefon zostaje jedynym pilotem, a wtedy nie ma skąd wziąć adresu.

Zeskanuj kod telefonem podłączonym do tej samej sieci — w przeglądarce telefonu otworzy się osobny, wąski pilot.

  • Wybór telewizora i źródła.
  • Bieżący kanał, EPG i suwak filmu.
  • Poprzedni / następny, pauza, ±30 s, stop, wyciszenie, głośność, panel na TV.
  • Zakładki: ulubione, katalogi, ostatnie, szukaj.

Przycisk Pilot w górnym pasku panelu otwiera to samo okno na komputerze.

iPhone: gdy Safari odmawia otwarcia. Safari na iOS 26 nie otwiera adresów http:// przychodzących z innej aplikacji — na przykład z aparatu po zeskanowaniu kodu — i pokazuje komunikat „żądanie dotyczyło adresu URL HTTP, dozwolone są tylko adresy URL HTTPS". Przytrzymaj wtedy baner aparatu, wybierz Skopiuj łącze i wklej je w pasek adresu Safari — wklejony adres otwiera się normalnie. Można też użyć innej przeglądarki, w niej kod działa od razu. Sam kod jest poprawny; program pracuje w sieci domowej po zwykłym HTTP, bo HTTPS wymagałby certyfikatu instalowanego ręcznie na każdym telefonie.

14. Ustawienia PANEL TV

To samo ustawia się także na telewizorze. Przycisk Ustawienia stoi na ekranie źródeł i w nagłówku listy kanałów, a ekran obsługuje się pilotem. Komputer nie jest do niczego potrzebny — panel daje to samo, tylko wygodniej przy dłuższych wpisach, jak adresy czy klucz TMDb.
  1. Wielkość napisów na listach kanałów. Trzy stopnie: normalna, duża, bardzo duża. Dotyczy listy otwieranej w trakcie oglądania klawiszem w lewo oraz pełnego ekranu z kanałami. Rośnie nazwa kanału i nazwa audycji. Im większe napisy, tym mniej pozycji mieści się na ekranie — dlatego stopnie tak się nazywają. Zmiana działa przy następnym otwarciu listy; wystarczy ją zamknąć i otworzyć ponownie, bez restartu programu. Domyślnie zostaje rozmiar dotychczasowy.
  2. Pilot na telefonie. Kod QR i adres strony pilota. Telefon musi być w tej samej sieci.
  3. Telewizory. Dodaj kolejny TV, wklejając pełny adres z jego ekranu, razem z token. Telewizor serwujący stronę jest zawsze dostępny jako „Ten telewizor”.
  4. Klawisze multimedialne. Pauza i przewijanie na klawiaturze sterują TV także przy zminimalizowanej przeglądarce. Przejmują te klawisze innym programom — wyłącz, jeśli przeszkadza. Wymaga kliknięcia na stronie, gdy przeglądarka zablokuje dźwięk.
  5. Klucz TMDb. Klucz API v3 do opisów i ocen. Plakaty działają bez klucza.
  6. Źródła. Lista, dodawanie i usuwanie. Usunięcie źródła czyści też jego listę i EPG na telewizorze.
  7. Kopia zapasowa. Pobiera plik JSON ze źródłami, lokalnymi playlistami radiowymi, ulubionymi, historią, pozycjami VOD, ręcznymi dopasowaniami EPG i ustawieniami. Plik zawiera również dane logowania zapisane przy źródłach — przechowuj go bezpiecznie. Przywrócenie zastępuje bieżące dane. Limit pliku: 10 MB.
  8. Aktualizacja programu. Pole na adres i przycisk Sprawdź. Pod podanym adresem ma leżeć mały plik update.json z numerem najnowszej wersji, adresem pakietu, sumą kontrolną i opisem zmian. Program łączy się z tym adresem wyłącznie po naciśnięciu przycisku — nigdy sam z siebie. Gdy jest nowsza wersja, przycisk Pobierz i zainstaluj pobiera pakiet, sprawdza sumę kontrolną i podpis (pakiet podpisany innym kluczem jest odrzucany), a na końcu oddaje go instalatorowi Androida, który pyta o zgodę na ekranie telewizora. 16. Rozwiązywanie problemów

Ekran ACTIVATION REQUIRED wraca albo kod jest odrzucany

  • Wyślij request code skopiowany z tego telewizora.
  • W temacie maila użyj dokładnie HPL IPTV E2+ Radio activation.
  • Wklej cały otrzymany kod, bez spacji na końcu i bez ucięcia.
  • Kod z innego telewizora nie zadziała na tym.

Panel się nie otwiera

  1. Sprawdź, czy aplikacja jest uruchomiona na TV — panel działa tylko wtedy.
  2. Komputer i telewizor muszą być w tej samej sieci. Wyłącz izolację klientów Wi-Fi w routerze.
  3. Wklej cały adres z ekranu, razem z token.
  4. Gdy TV pokazuje czerwony komunikat, że panel nie działa, uruchom aplikację ponownie.

Źródło jest, ale lista jest pusta

Wejdź w źródło na telewizorze albo w panelu użyj Pobierz wybraną playlistę ponownie. Panel trzyma kopię listy w przeglądarce; samo dodanie źródła nie wczytuje jeszcze kanałów.

Brak EPG

  • IPTV / Xtream: podaj adres XMLTV przy źródle i uruchom import (zielony na TV albo przycisk w Ustawieniach).
  • Enigma2: program powinien przyjść z tunera. Sprawdź OpenWebif i czy bukiet jest wczytany.
  • Radio nie ma telewizyjnego EPG.

Jeden kanał nie ma programu, a reszta ma

To zwykle nazwa: u dostawcy inna niż w pliku XMLTV, więc automat nie ma po czym rozpoznać kanału. Otwórz Ustawienia → Program telewizyjny → Ręczne dopasowanie EPG, wskaż właściwą pozycję i uruchom import jeszcze raz — rozdział 15.

Obraz zamarza albo kanał nie odpowiada

Program sam ponawia strumień. Gdy w katalogu jest zapasowe łącze, przełączy się na nie. Sprawdź konto dostawcy, liczbę jednoczesnych połączeń i czy ten sam adres działa w VLC na komputerze.

Komunikat Brak sieci · czekam na połączenie mówi, że problem jest po stronie Wi-Fi albo routera; program wróci do obrazu sam, gdy sieć wróci.

Plakaty nie wymagają TMDb. Opisy i oceny wymagają klucza API v3 w Ustawieniach oraz internetu w przeglądarce.

Pilot na telefonie nie steruje

1. What the program is

HPL IPTV E2+ Radio is an Android TV app. It plays IPTV channels, Enigma2 tuners and internet radio. Playlists, EPG, films and settings are added from a computer or phone through a browser panel — the same PC that runs HPL ink Enigma2+ IPTV, or any other browser on the home network.

  • M3U / M3U8 playlist from a URL.
  • Xtream Codes account (server, port, user, password).
  • Enigma2 tuner with OpenWebif — bouquets, stream and guide from the receiver.
  • Internet radio from an M3U playlist (URL or a file from the computer).
  • XMLTV guide, films and series from the playlist, favourites, history, reminders and backup.
Network: the TV, computer and phone must be on the same local network. The panel and the activation page are not a public website — they work only at home, at the address shown on the TV.

2. Program activation

On the first start the program does not open the source list. The TV shows only the ACTIVATION REQUIRED screen. That screen is in English. Until a valid activation code is entered, the rest of the program stays closed.

An activation code from one television will not work on another.

Easiest path — a computer

The activation code is long. Pasting it in a computer browser is easier than typing with the TV remote.

1. AddressOn the TV, read OPEN THIS ADDRESS ON A COMPUTER, e.g. http://192.168.1.50:8091/activate.
2. Request codeOpen the address in a browser and select Copy code.
3. SendSend the copied code to hplink.soft@proton.me.
4. ActivatePaste the code you receive into ACTIVATION CODE and select Activate.

Use this exact subject line:

HPL IPTV E2+ Radio activation

A successful activation shows Activated. The program is starting on the TV. The television then opens the normal sources screen. Later starts do not show this screen again.

The same steps on the TV

If no computer is at hand, the same fields are on the TV screen:

  • DEVICE ID — a short identifier in the form HPL-XXXX-XXXX-XXXX.
  • REQUEST CODE — the long code to send.
  • Copy code — copies the request code (when the TV has a clipboard).
  • ACTIVATION CODE — field for the code you receive.
  • Activate — submits the code.
  • Close program — closes the app.

This code is not valid for this device. means the pasted code does not match this television. Check that you sent the request code from this device and that you pasted the entire code you received, with nothing cut off.

Other versions: hplspam1-jpg.github.io/HPL-ink-Software

Network during activation: the /activate address works only when the TV is on the local network. If the TV shows no network connection, connect Wi-Fi or a cable and start the program again.

3. First start

Requirements

  • A television or box with Android TV / Google TV, Android 8.0 or newer.
  • The same local network for the TV, computer and phone.
  • For IPTV: an M3U/M3U8 playlist or Xtream Codes details from the provider.
  • For Enigma2: a receiver with OpenWebif enabled on the same network.
  • For radio: an M3U playlist at a URL or a .m3u file from the computer (6 MB maximum).
  • Optional TMDb API v3 key — only for descriptions, ratings and original titles. Posters come from the playlist.

After activation

  1. The TV shows the sources screen and a large panel address, e.g. http://192.168.1.50:8091/?token=….
  2. Copy the entire address, including the token parameter.
  3. Open it in a browser on the computer.
  4. In the panel, under Settings, add the first source.
  5. Go back to the TV and open that source to load the list.
Important: an address without token will not open the panel. When adding a second TV, always paste the full address from its screen.

The „Later" panel — three upcoming programmes

One minute before the current programme ends, a list of the next three items in the guide for that channel appears at the right edge for ten seconds — time and title. The first item, the one about to start, is highlighted.

  • OK or BACK closes the panel at once.
  • The panel can be switched off for good in the panel settings (chapter 14).
  • Nothing is fetched from the network — the data comes from the guide stored on the TV.
  • A dropped stream is retried several times. If the same folder has a backup link, the program switches to it and shows a failover notice. When there is no replacement it says so: no backup link for this channel.
  • Film position is stored. The next opening resumes from that point.
  • If the picture freezes or the channel does not respond after the retries, a message with the attempt count is shown.
  • A minute of healthy picture clears the memory of failed links — after a short network overload the program has somewhere to switch again.

When the picture stops or the network drops

  • The picture froze while the sound keeps playing. The program counts the frames actually drawn on the screen. When none arrives for a dozen or so seconds it shows No picture detected. Restoring the picture and rebuilds the connection on its own. Such a freeze used to pass unnoticed, because the time counter kept moving along with the sound.
  • The network dropped. After a lost Wi-Fi connection or a router restart the screen shows No network · waiting for a connection. The program does not burn through its retries and does not declare the channel dead. When the network returns it shows Network is back · resuming playback and picks the picture up again — without leaving the channel. Radio behaves the same way, and the browser panel comes back up after the TV changes address.

Radio reacts to the network like the channel player: after a lost connection it waits with No network · waiting for a connection and resumes the station by itself once the network is back.

8. Guide on the TV TV

INFO on the channel list opens the full schedule for one channel. Programmes are grouped by day. OK on an item can play the channel now or set a reminder. A reminder can also switch the TV at the start time.

The guide refreshes itself once a day. Never while you are watching — the job waits in a queue and starts when nobody is watching. If an import is already running and you start a channel, it stops at the nearest step and returns to the queue. A television switched off for a few days catches up at its next start.

A manual XMLTV import is started with GREEN on the channel list or with the button in the panel. Download, name matching and storage run on the TV in the background and may take a few minutes. An Enigma2 tuner needs no import — the guide comes from OpenWebif. Radio does not use the TV guide.

An interrupted import no longer wipes the guide. New programmes go to a holding area first, and the old guide lives until the whole file has been read correctly. The swap happens in one step. A dropped network or a damaged XMLTV file therefore leaves the guide as it was — not empty or half filled. While importing, the program also clears programmes older than half a day and further away than eight days.

A channel the automatic matching cannot recognise by name can be assigned to an XMLTV entry by hand, from the panel — see chapter 15.

Starting the program from the computer

The panel answers only while the program is running on the television. The panel server lives inside the program, so with the application closed there is nobody to take the command — which is why starting it from the computer uses the television's own IP control, not our panel.

Step 1 — on the television TV

  1. Press HOME and open Settings.
  2. Find BRAVIA Settings → IP control. On some releases the path reads Network → Home network setup → IP control.
  3. Turn remote control on.
  4. Set Authentication to Pre-Shared Key and enter your own key, for example hpl. This is a password for controlling the television — do not reuse a password you use elsewhere.

Step 2 — in the PC program

  1. Enter the same key in the TV pre-shared key field of the TV profile. The key is encrypted for the current Windows account, just like the panel token.
  2. Press Fetch from TV — the program downloads the list of applications installed on the television.
  3. Pick HPL IPTV E2+ Radio from the list and save the profile. You choose once; the application id is not hard-coded, because one television may hold several variants of the program.
  4. From now on the Start the program on the television button opens the application without reaching for the remote.
The television must be on. IP control does not wake it from standby — with the set off the button reports that the television is in standby. The computer and the television must be on the same home network.
After the television is disconnected from power the IP control setting may return to its default. If the button stops working, check Step 1 first — the pre-shared key sometimes has to be entered again.

Sending a new version from the computer

The Send a new version to the TV button in the PC program (from version 1.10) installs a chosen .apk file straight from the computer's disk, with no server and no cable. The computer serves the file over the home network for a moment and hands the TV its address — the television does the rest itself.

  • The application must be open on the TV; it is the one that accepts the command. If it is closed, use Start the program on the TV first.
  • Before sending, the program shows which version is on the TV and which one will be installed.
  • The TV verifies the checksum and the package signature, and you still confirm the installation with the remote — exactly as with an update from an address.
  • On first use Windows may ask about the firewall: allow it for the private network.

11. Films and series PANEL

The Films and Series tabs show items that the playlist marks as VOD (paths or metadata such as /movie/ and /series/). Posters come from the playlist. A TMDb key in Settings adds the description, rating and original title only after an item is opened.

  • Sorting: newest, oldest, playlist order, most episodes (series).
  • Filters: with poster only, to watch.
  • The ✚ badge on a poster marks an item to watch.
  • In series: folders → series → season → episode. Next unwatched resumes from the first unwatched episode.
  • Play on the TV starts the item on the selected television.

The VOD filter in Settings hides these items on the ordinary channel list so they do not mix with live TV.

Only IPTV lists are taken into account — M3U and Xtream playlists. An Enigma2 tuner has no VOD catalogue, and name-based recognition could take ordinary channels such as „Polsat Seriale HD" for films. That is why the Films button does not appear for a tuner source; its place is taken by Recordings. The panel and the TV recognise films by the same rule, so the list in the browser matches what is on the screen.

Films on the TV TV

The same catalogue can be opened without a computer: the Films button sits on the sources screen and in the channel list header. The screen shows a grid of posters, the folder selector above it, and the full title of the highlighted item below — on the tile it is trimmed to two lines.

  • The list comes from the TV's own memory: this screen does not contact the provider. When the memory is empty it says so, instead of downloading tens of megabytes unasked.
  • OK plays, BACK returns.

12. Phone remote PANEL

The QR code sits in two places: in the panel settings and — since version 2.16 — on the sources screen of the television, next to the panel address, labelled “REMOTE ON YOUR PHONE”. The second one matters more than it sounds: with the computer switched off the phone is the only remote left, and there is nowhere else to read the address from.

Scan the code with a phone on the same network — a separate, narrow remote opens in the phone browser.

  • TV and source selection.
  • Current channel, EPG and a film seek slider.
  • Previous / next, pause, ±30 s, stop, mute, volume, panel on the TV.
  • Tabs: favourites, folders, recent, search.

The Remote button in the panel header opens the same window on the computer.

iPhone: when Safari refuses to open the page. Safari on iOS 26 does not open http:// addresses that arrive from another app — from the camera after scanning a code, for example — and shows “the request was for an HTTP URL, only HTTPS URLs are allowed”. Press and hold the camera banner, choose Copy Link and paste it into Safari's address bar; a pasted address opens normally. Another browser works straight away. The code itself is correct; the program runs over plain HTTP on your home network, because HTTPS would need a certificate installed by hand on every phone.

14. Settings PANEL TV

The same settings are on the television. The Settings button sits on the sources screen and in the channel list header, and the screen is operated with the remote. No computer is needed — the panel offers the same, only more comfortably for longer entries such as addresses or the TMDb key.
  1. Text size in channel lists. Three steps: normal, large, very large. Applies to the list opened while watching with the left key and to the full channel screen. Both the channel name and the programme name grow. The larger the text, the fewer entries fit on screen — hence the names of the steps. The change takes effect the next time the list is drawn; just close and open it again, no restart needed. The default keeps the previous size.
  2. Remote on your phone. QR code and remote page address. The phone must be on the same network.
  3. TV sets. Add another TV by pasting the full address from its screen, including token. The television serving this page is always available as “This TV”.
  4. Media keys. Pause and seek keys on the keyboard control the TV even when the browser is minimised. They take those keys from other programs — turn the option off if that gets in the way. A click on the page may be required if the browser blocked audio.
  5. TMDb key. API v3 key for descriptions and ratings. Posters work without a key.
  6. Sources. List, add and delete. Deleting a source also clears its list and EPG on the TV.
  7. Backup. Downloads a JSON file with sources, local radio playlists, favourites, history, VOD positions, manual EPG matches and program settings. The file also contains the login details stored with your sources — keep it safe. Restore replaces the current data. File limit: 10 MB.
  8. Program update. An address field and a Check button. The address should point at a small update.json file holding the latest version number, the package address, a checksum and a description of the changes. The program contacts that address only when you press the button — never on its own. The result of the check shows the version that is waiting next to the one installed, the package size and the list of changes — before anything is downloaded. When a newer version exists, Download and install fetches the package, verifies the checksum and the signature (a package signed with a different key is rejected), and hands it to the Android installer, which asks for confirmation on the TV screen. A silent install is not possible; the television must also allow the program to install packages once.
  9. Bouquets. The bouquets of the selected source with a channel count each. An unticked bouquet disappears from the channel list on the TV, from bouquet switching while watching and from the rail in the Channels tab. Its channels stay in search, in favourites and in Films — the point is shorter lists, not hiding part of your own playlist.
  10. TV guide. Fetch EPG for the selected source starts an XMLTV import on the TV. Below it sits the Manual EPG matching card — described in chapter 15.
  11. Channel and radio station list. Fetch the playlist from the provider again (same as the blue remote key). Below the divider: hiding VOD items on the channel list, the next-programme notice — how many minutes ahead it should appear, or “off”, the „Later" panel — whether to show three upcoming programmes a minute before the current one ends (chapter 6), and the advance notice of a reminder — 5, 10, 15 or 30 minutes before a programme you asked to be reminded about; “off” leaves only the reminder itself, a minute before.
  12. Guide stored on the TV. How many programmes for how many channels sit in the database, how much space they take and how far ahead the guide runs — that is, when it needs refreshing. The Clear the guide button removes programmes and automatic matches; manual matches are kept and come back into play at the next import.
  13. Storage. The TV (channel logos and film posters, each with its own limit) and this browser (a copy of the lists so the panel opens instantly) are listed separately. Clearing browser storage deletes nothing on the TV.

16. Troubleshooting

The ACTIVATION REQUIRED screen returns or the code is rejected

  • Send the request code copied from this television.
  • Use the exact subject HPL IPTV E2+ Radio activation.
  • Paste the entire code you received, with no trailing space and nothing cut off.
  • A code from another television will not work on this one.

The panel does not open

  1. Check that the app is running on the TV — the panel works only then.
  2. The computer and the TV must be on the same network. Turn off Wi-Fi client isolation on the router.
  3. Paste the full address from the screen, including token.
  4. If the TV shows a red message that the panel is not working, start the app again.

The source is there, but the list is empty

Open the source on the TV or use Fetch the selected playlist again in the panel. The panel keeps a copy of the list in the browser; adding a source does not load the channels by itself.

No EPG

  • IPTV / Xtream: enter an XMLTV address on the source and run the import (green on the TV or the button in Settings).
  • Enigma2: the guide should come from the receiver. Check OpenWebif and that a bouquet is loaded.
  • Radio has no TV guide.

One channel has no guide while the rest do

Usually it is the name: different at the provider than in the XMLTV file, so the automatic matching has nothing to recognise the channel by. Open Settings → TV guide → Manual EPG matching, point at the right entry and run the import once more — chapter 15.

The picture freezes or the channel does not respond

The program retries the stream on its own. If the folder has a backup link, it switches to it. Check the provider account, the number of concurrent connections, and whether the same address plays in VLC on a computer.

The message No picture detected. Restoring the picture means the picture stopped while the sound kept playing and the program is rebuilding the connection — nothing to do. The message No network · waiting for a connection means the problem is with Wi-Fi or the router; the program returns to the picture by itself once the network is back.

The picture is stretched or has bars

Hold OK in the player and change the mode: Fit shows the whole frame with bars, Zoom fills the screen at the cost of the edges, Stretch is the default. On 16:9 material all three modes give the same picture.

A film does not start, but a TV channel does

Check that the account includes VOD and that the playlist has separate film paths. The VOD filter in Settings does not block the Films / Series tabs in the panel, nor the Films screen on the TV — it only cleans the channel list.

Film descriptions are missing

Posters do not need TMDb. Descriptions and ratings need an API v3 key in Settings and internet access in the browser.

The phone remote does not control the TV

The phone must be on the same network. Scan the code again from the panel that is currently open. Check that the remote has the correct television selected.
